Séance 17 · Le responsive design

Plus de la moitié des visiteurs regardent les sites sur un téléphone. Un site responsive s'adapte à toutes les tailles d'écran : téléphone, tablette, ordinateur.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, mode appareil de F12 (Ctrl + Shift + M)
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Ajouter la balise <meta name="viewport"> et tester ma page en mode téléphone avec F12.
  • Écrire des media queries @media pour changer le style selon la largeur de l'écran.
  • Construire une page « mobile first » avec des images et des grilles qui s'adaptent.

🔁 Rappel

Grid : grid-template-columns: repeat(3, 1fr), auto-fit + minmax, grid-template-areas. Flexbox : flex-wrap: wrap et flex: 1 1 250px.

📒 La note : ce qu'il faut comprendre

1La balise viewport

Sans cette ligne dans le <head>, le téléphone affiche la page comme sur un ordinateur, toute petite. Elle est obligatoire pour le responsive.

HTML
<meta name="viewport" content="width=device-width, initial-scale=1.0">

💡 Astuce : Bonne nouvelle : VS Code l'ajoute automatiquement quand tu tapes ! + Entrée.

2Tester en mode téléphone

Ouvre F12, puis clique sur l'icône 📱 (ou Ctrl + Shift + M). Tu peux choisir un modèle de téléphone (iPhone, Samsung…) ou changer la largeur à la main.

  • Téléphone : moins de 600px.
  • Tablette : entre 600px et 900px.
  • Ordinateur : plus de 900px.

3Les media queries

Une media query, c'est une condition : « SI l'écran fait moins de 600px, ALORS applique ces règles ».

Les règles dans @media remplacent les règles normales quand la condition est vraie. On les écrit à la fin du fichier CSS.

HTML
<div class="boite">Réduis la fenêtre : je deviens orange sur téléphone !</div>
CSS
.boite { background: #288b8b; color: white; padding: 20px; }

/* SI l'écran fait 600px ou moins */
@media (max-width: 600px) {
  .boite { background: #e67e22; }
}
Résultat

💡 Astuce : Le cadre du résultat est petit : la boîte est peut-être déjà orange ! Ouvre l'exemple de la séance et change la largeur de la fenêtre.

4Mobile first

Mobile first = on écrit d'abord le CSS pour le téléphone (une seule colonne), puis on ajoute des colonnes pour les grands écrans avec min-width.

C'est plus simple, car sur téléphone tout est souvent l'un sous l'autre.

CSS
/* 1. Téléphone : une colonne */
.cartes { display: grid; grid-template-columns: 1fr; gap: 15px; }

/* 2. Tablette : 2 colonnes */
@media (min-width: 600px) {
  .cartes { grid-template-columns: repeat(2, 1fr); }
}

/* 3. Ordinateur : 4 colonnes */
@media (min-width: 900px) {
  .cartes { grid-template-columns: repeat(4, 1fr); }
}

5Les images et les textes fluides

  • img { max-width: 100%; height: auto; } → une image ne dépasse jamais de son parent.
  • Utilise des largeurs en % ou max-width au lieu de width fixe en px.
  • Sur mobile : on cache ce qui n'est pas important (display: none), on passe les menus en colonne (flex-direction: column).
CSS
img { max-width: 100%; height: auto; }
.conteneur { width: 90%; max-width: 1100px; margin: 0 auto; }

🛠️ Exercices pas à pas

Exercice 1 · Le testfacile

  1. Copie ton travail de la séance 15 (navbar + cartes) dans seance17/.
  2. Vérifie que la balise <meta name="viewport"> est dans le <head>.
  3. Ouvre F12 → mode appareil (Ctrl + Shift + M) → choisis un téléphone. Note tout ce qui ne va pas (texte trop petit, élément qui dépasse…).

Exercice 2 · Les media queriesmoyen

  1. Ajoute img { max-width: 100%; height: auto; }.
  2. À la fin du CSS, écris @media (max-width: 600px) { … }.
  3. Dedans : passe la navbar en colonne (flex-direction: column), réduis la taille du <h1>, réduis les padding.
  4. Vérifie en mode téléphone qu'il n'y a plus de barre de défilement horizontale.

Exercice 3 · Une grille qui s'adaptedifficile

  1. Crée une grille de 8 cartes en mobile first : 1 colonne par défaut.
  2. Ajoute @media (min-width: 600px) → 2 colonnes, puis @media (min-width: 900px) → 4 colonnes.
  3. Cache un élément décoratif sur téléphone avec display: none.

🏆 Défi bonus : L'écran caméléon

Crée une page qui affiche en grand « 📱 Téléphone », « 📟 Tablette » ou « 💻 Ordinateur » selon la largeur de l'écran, avec une couleur de fond différente à chaque fois. Utilise display: none dans les media queries.

Bonus : teste ta page sur ton vrai téléphone (même Wi-Fi que l'ordinateur, adresse IP de Live Server).

⚠️ Erreurs fréquentes

J'ai oublié la balise viewport : tout est minuscule sur téléphone
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Ma media query est au début du CSS et ne marche pas
Je mets les media queries à la fin du fichier
@media (max-width: 600px) { .menu { … } : il manque une accolade
Une } pour la règle ET une } pour la media query
Une image dépasse et crée un défilement horizontal
max-width: 100% sur les images, pas de width fixe trop grand

📚 Vocabulaire

Responsive
Qui s'adapte à toutes les tailles d'écran.
Viewport
La zone visible de la page dans le navigateur.
Media query
Une condition @media qui applique du CSS selon l'écran.
Breakpoint
Une largeur où le design change (600px, 900px…).
Mobile first
Écrire d'abord le CSS du téléphone, puis celui des grands écrans.
