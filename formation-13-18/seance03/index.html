Séance 03 · Texte, liens et images

Une page sans liens ni images, c'est triste ! Aujourd'hui tu apprends à mettre du texte en valeur, à créer des liens et à afficher des images.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, Unsplash ou Picsum pour les images
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Mettre du texte en valeur avec <strong> et <em>.
  • Créer des liens vers un autre site et vers une autre page de mon site.
  • Afficher une image avec <img> et lui donner un texte alt.

🔁 Rappel

Une page HTML a un squelette : <head> pour les infos invisibles, <body> pour le contenu visible. On structure avec <h1>…<h6> et <p>.

📒 La note : ce qu'il faut comprendre

1Mettre du texte en valeur

<strong> met un mot important en gras. <em> insiste sur un mot (en italique).

On peut aussi utiliser <mark> pour surligner.

HTML
<p>Le HTML est <strong>très important</strong>, il faut <em>bien</em> le pratiquer. <mark>Révise ce soir !</mark></p>
Résultat

2Les liens avec <a>

La balise <a> crée un lien. L'attribut href donne l'adresse où aller.

Un attribut est une information en plus, écrite dans la balise ouvrante : nom="valeur".

target="_blank" ouvre le lien dans un nouvel onglet.

HTML
<a href="https://www.wikipedia.org" target="_blank">Aller sur Wikipédia</a>
<br>
<a href="contact.html">Ma page contact</a>
Résultat

💡 Astuce : Pour un site extérieur, l'adresse commence par https://. Pour une page de ton site, écris juste le nom du fichier.

3Les images avec <img>

<img> est une balise orpheline. src = l'adresse de l'image, alt = la description de l'image.

Le texte alt s'affiche si l'image ne charge pas et il est lu par les logiciels pour les personnes aveugles. Il est obligatoire.

HTML
<img src="https://picsum.photos/seed/plage/300/180" alt="Une plage au coucher du soleil" width="300">
Résultat

4Les chemins : où est mon image ?

On range ses images dans un dossier images/. Le chemin dépend de l'endroit où se trouve ton fichier HTML :

  • photo.jpg → l'image est dans le même dossier que la page.
  • images/photo.jpg → l'image est dans le dossier images à côté de la page.
  • ../photo.jpg → l'image est dans le dossier parent (on remonte d'un niveau).
Schéma
seance03/
├── index.html
├── contact.html
└── images/
    └── tunis.jpg

<!-- dans index.html : -->
<img src="images/tunis.jpg" alt="Avenue Habib Bourguiba">

💡 Astuce : Pas d'espace ni d'accent dans les noms de fichiers : ma-photo.jpg et pas Ma Photo é.jpg.

5Une image cliquable

On peut mettre une image dans un lien : toute l'image devient cliquable.

HTML
<a href="https://fr.wikipedia.org/wiki/Djerba" target="_blank">
  <img src="https://picsum.photos/seed/djerba/200/130" alt="Djerba" width="200">
</a>
Résultat

👉 Ouvre l'exemple complet de la séance, puis fais clic droit → Inspecter pour voir son code.

🛠️ Exercices pas à pas

Exercice 1 · Ma villefacile

  1. Crée seance03/index.html avec le squelette.
  2. Écris un <h1> avec le nom de ta ville et 2 paragraphes de présentation.
  3. Mets en gras (<strong>) le nom de 3 lieux connus de ta ville.

Exercice 2 · Ajouter des imagesfacile

  1. Crée un dossier images dans seance03.
  2. Télécharge 2 photos de ta ville (sur Unsplash) et range-les dans images/.
  3. Affiche-les avec <img src="images/…" alt="…" width="300">.
  4. Vérifie : écris volontairement un mauvais nom d'image. Que voit-on ? (le texte alt !) Puis corrige.

Exercice 3 · Des liens utilesmoyen

  1. Ajoute un <h2>Pour en savoir plus</h2>.
  2. Crée un lien vers la page Wikipédia de ta ville qui s'ouvre dans un nouvel onglet.
  3. Crée un lien vers Google Maps de ta ville.
  4. Rends une de tes images cliquable (l'image dans un <a>).

🏆 Défi bonus : Mini-site de 2 pages

Crée une deuxième page monuments.html qui présente 2 monuments de ta ville avec une image chacun.

Ajoute un lien « Voir les monuments » dans index.html et un lien « ← Retour à l'accueil » dans monuments.html. Les deux pages doivent être reliées !

⚠️ Erreurs fréquentes

<img src="images/Photo.JPG"> alors que le fichier s'appelle photo.jpg
Le nom doit être exactement le même (majuscules comprises)
J'oublie l'attribut alt
Toujours une description : alt="La plage de Hammamet"
<a href="www.google.com">
Il faut le début complet : href="https://www.google.com"
J'oublie les guillemets : href=page.html
Les valeurs vont entre guillemets : href="page.html"

📚 Vocabulaire

Attribut
Une information en plus dans la balise ouvrante : href, src, alt…
Lien hypertexte
Un texte ou une image sur lequel on clique pour aller ailleurs.
URL
L'adresse d'une page web, ex. https://www.wikipedia.org.
Chemin relatif
L'adresse d'un fichier à partir de la page actuelle, ex. images/chat.jpg.
Texte alternatif
La description d'une image dans alt.
