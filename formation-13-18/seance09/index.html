Séance 09 · Le texte, les polices et les unités

Un texte bien choisi rend une page belle et facile à lire. Aujourd'hui tu utilises Google Fonts, tu règles la taille du texte et tu donnes du style aux liens et aux listes.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, Google Fonts
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Changer la police avec font-family et ajouter une police de Google Fonts.
  • Régler la taille, la graisse, l'alignement et l'espacement du texte, avec les unités px, rem et %.
  • Styler les liens selon leur état (:hover…) et changer les puces des listes.

🔁 Rappel

Une règle CSS = sélecteur { propriété: valeur; }. On vise par balise p, par classe .nom, par id #nom.

📒 La note : ce qu'il faut comprendre

1Les propriétés du texte

  • font-size : la taille (ex. 18px).
  • font-weight : la graisse (normal, bold, ou 100 à 900).
  • font-style: italic : l'italique.
  • text-align : l'alignement (left, center, right, justify).
  • text-transform: uppercase : TOUT EN MAJUSCULES.
  • line-height : l'espace entre les lignes (ex. 1.6).
  • letter-spacing : l'espace entre les lettres.
  • text-decoration: none : enlève le soulignement.
HTML
<h2>Le match de samedi</h2>
<p>L'équipe a gagné 3 à 1 après un match très serré. Les supporters ont chanté jusqu'à la fin.</p>
<p class="petit">Photo : club junior</p>
CSS
h2 { text-align: center; text-transform: uppercase; letter-spacing: 3px; }
p { font-size: 15px; line-height: 1.8; }
.petit { font-size: 12px; font-style: italic; color: gray; }
Résultat

2Les polices et Google Fonts

font-family choisit la police. On donne toujours une police de secours à la fin : serif, sans-serif ou monospace.

Sur fonts.google.com : choisis une police → Get font → Get embed code → copie le <link> dans ton <head> et la ligne font-family dans ton CSS.

HTML
<head>
  <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="style.css">
</head>
CSS
body {
  font-family: 'Poppins', sans-serif;
}

💡 Astuce : Pas plus de 2 polices par site : une pour les titres, une pour le texte. Sinon ça devient illisible.

3Les unités : px, rem, %

  • px : une taille fixe en pixels. Simple pour commencer.
  • rem : relatif à la taille du texte de la page (16px par défaut). 2rem = 32px. Pratique pour que tout s'agrandisse ensemble.
  • % : un pourcentage de l'élément parent. width: 50% = la moitié du parent.
  • vw / vh : un pourcentage de la largeur / hauteur de l'écran.
HTML
<p class="a">16px</p>
<p class="b">1.5rem = 24px</p>
<p class="c">2rem = 32px</p>
CSS
.a { font-size: 16px; }
.b { font-size: 1.5rem; }
.c { font-size: 2rem; }
Résultat

4Les liens et leurs états

Un lien a plusieurs états : :link (pas encore visité), :visited (déjà visité), :hover (la souris est dessus), :active (on clique).

L'ordre est important ! Retiens LoVe HAte : :link, :visited, :hover, :active. Sinon le :hover ne marche pas sur les liens visités.

HTML
<p><a href="#">Passe la souris sur moi</a></p>
CSS
a:link { color: #288b8b; }
a:visited { color: #8e44ad; }
a:hover { color: #e67e22; text-decoration: none; }
a:active { color: red; }
Résultat

5Styler les listes

list-style-type change les puces : disc, circle, square, decimal, upper-roman, none…

HTML
<ul class="carre"><li>Carré</li><li>Carré</li></ul>
<ol class="romain"><li>Un</li><li>Deux</li></ol>
<ul class="aucun"><li>✅ Sans puce</li><li>✅ Sans puce</li></ul>
CSS
.carre { list-style-type: square; color: #288b8b; }
.romain { list-style-type: upper-roman; }
.aucun { list-style-type: none; padding-left: 0; }
Résultat

💡 Astuce : list-style-type: none est très utilisé pour faire des menus de navigation.

🛠️ Exercices pas à pas

Exercice 1 · Mon articlefacile

  1. Crée seance09/index.html et style.css : un article sur un événement (match, concert, sortie scolaire) avec un titre, un chapeau (class="chapeau"), 3 paragraphes et une liste.
  2. Règle le body : taille 17px, line-height: 1.6.
  3. Centre le <h1> et mets-le en majuscules avec un espacement de lettres.

Exercice 2 · Google Fontsmoyen

  1. Choisis 2 polices sur Google Fonts : une originale pour les titres, une simple pour le texte.
  2. Ajoute le <link> dans le <head> (AVANT ton style.css).
  3. Applique la police des titres à h1, h2 et l'autre au body.

Exercice 3 · Liens et listesmoyen

  1. Ajoute 3 liens dans ton article. Style les 4 états dans l'ordre LoVe HAte.
  2. Enlève le soulignement des liens, et remets-le seulement au :hover.
  3. Change les puces de ta liste (essaie square, puis none avec un emoji au début de chaque <li>).

🏆 Défi bonus : L'affiche de concert

Crée une affiche de concert en HTML/CSS : nom de l'artiste énorme (5rem), date, lieu, prix, liste des titres chantés.

Utilise uniquement des propriétés de texte (pas d'image) : polices Google, tailles, majuscules, espacements, couleurs. Fais-la la plus belle possible !

⚠️ Erreurs fréquentes

font-family: Poppins mais la police ne change pas
J'ai oublié le <link> de Google Fonts dans le <head>
font-size: 20 sans unité
Toujours une unité : 20px ou 1.25rem
Mon :hover ne marche pas sur les liens visités
Je respecte l'ordre LoVe HAte : link, visited, hover, active
J'utilise 5 polices différentes
2 polices maximum par site

📚 Vocabulaire

Police (font)
Le dessin des lettres.
Graisse
L'épaisseur du texte (font-weight).
Interligne
L'espace entre les lignes (line-height).
px
Pixel : un petit point de l'écran. Unité fixe.
rem
Unité relative à la taille du texte de base (16px).
Pseudo-classe
Un état d'un élément, comme :hover (survolé).
