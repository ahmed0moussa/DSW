Séance 09 · Fonds, dégradés et images

Aujourd'hui tu crées une bannière d'événement avec une image de fond, des dégradés de couleurs et des effets sur les images.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, CSS Gradient, Unsplash
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Mettre une image de fond avec background-image et la régler avec background-size et background-position.
  • Créer des dégradés avec linear-gradient et radial-gradient.
  • Recadrer une image avec object-fit et lui appliquer des effets avec opacity et filter.

🔁 Rappel

Chaque élément est une boîte : contenu, padding, border, margin. On met box-sizing: border-box partout.

📒 La note : ce qu'il faut comprendre

1L'image de fond

  • background-image: url("images/fond.jpg"); → l'image de fond.
  • background-size: cover; → l'image couvre toute la boîte (sans se déformer).
  • background-position: center; → on centre l'image.
  • background-repeat: no-repeat; → l'image ne se répète pas.
HTML
<div class="banniere"><h2>Festival de Carthage</h2></div>
CSS
.banniere {
  height: 160px;
  background-image: url("https://picsum.photos/seed/festival/600/300");
  background-size: cover;
  background-position: center;
  color: white;
  padding: 20px;
}
Résultat

💡 Astuce : Pour que le texte reste lisible sur une photo, ajoute une couleur sombre transparente par-dessus (voir notion 3).

2Les dégradés

Un dégradé est une image créée par le CSS : on l'écrit donc dans background-image (ou background).

Va sur cssgradient.io pour créer ton dégradé et copier le code.

HTML
<div class="a">linear-gradient (gauche → droite)</div>
<div class="b">linear-gradient en diagonale, 3 couleurs</div>
<div class="c">radial-gradient (cercle)</div>
CSS
div { height: 60px; margin: 6px; border-radius: 8px; color: white; padding: 8px; }
.a { background: linear-gradient(to right, #288b8b, #e67e22); }
.b { background: linear-gradient(135deg, #8e44ad, #3498db, #1abc9c); }
.c { background: radial-gradient(circle, #f9d423, #e65c00); }
Résultat

3Image + voile sombre

On peut mettre plusieurs fonds l'un sur l'autre, séparés par une virgule. Le premier est au-dessus.

HTML
<div class="hero"><h2>Concert ce samedi</h2><p>Le texte reste lisible !</p></div>
CSS
.hero {
  height: 160px;
  padding: 20px;
  color: white;
  background-image:
    linear-gradient(rgba(0,0,0,0.6), rgba(0,0,0,0.2)),
    url("https://picsum.photos/seed/concert/600/300");
  background-size: cover;
}
Résultat

4object-fit : recadrer sans déformer

Si tu donnes une largeur ET une hauteur à une image, elle peut être écrasée. object-fit: cover la recadre proprement.

HTML
<img src="https://picsum.photos/seed/velo/400/400" alt="Image déformée">
<img class="cover" src="https://picsum.photos/seed/velo/400/400" alt="Image recadrée">
CSS
img { width: 140px; height: 90px; margin: 4px; }
.cover { object-fit: cover; }
Résultat

💡 Astuce : À gauche l'image est écrasée, à droite elle est recadrée avec object-fit: cover.

5opacity et filter

  • opacity: 0.5; → l'élément devient transparent à 50 %.
  • filter: grayscale(100%); → noir et blanc.
  • filter: blur(3px); → flou.
  • filter: brightness(130%); → plus lumineux. Aussi : sepia(), contrast(), hue-rotate()…
HTML
<img src="https://picsum.photos/seed/parc/300/200" alt="Normal">
<img class="gris" src="https://picsum.photos/seed/parc/300/200" alt="Gris">
<img class="flou" src="https://picsum.photos/seed/parc/300/200" alt="Flou">
<img class="sepia" src="https://picsum.photos/seed/parc/300/200" alt="Sépia">
<img class="transparent" src="https://picsum.photos/seed/parc/300/200" alt="Transparent">
CSS
img { width: 100px; height: 80px; object-fit: cover; margin: 3px; }
.gris { filter: grayscale(100%); }
.flou { filter: blur(3px); }
.sepia { filter: sepia(100%); }
.transparent { opacity: 0.4; }
Résultat

🛠️ Exercices pas à pas

Exercice 1 · La bannièrefacile

  1. Crée seance09/index.html avec un <header class="banniere"> qui contient le nom d'un festival ou d'un événement.
  2. Télécharge une photo sur Unsplash dans images/ et mets-la en fond de la bannière.
  3. Règle la hauteur (height: 300px), background-size: cover et background-position: center.

Exercice 2 · Lisibilité et dégradésmoyen

  1. Ajoute un voile sombre avec un linear-gradient transparent devant la photo.
  2. Crée sur cssgradient.io un dégradé pour le fond du <footer>.
  3. Fais un bouton (un lien <a class="bouton">) avec un fond en dégradé et des coins arrondis.

Exercice 3 · Les photos du programmemoyen

  1. Ajoute 3 images de la même taille (width: 200px; height: 150px;) avec object-fit: cover.
  2. Donne un filter différent à chaque image.
  3. Ajoute opacity: 0.6 sur une image « Événement terminé ».

🏆 Défi bonus : La galerie avant / après

Crée 6 images en noir et blanc (grayscale(100%)). Cherche sur W3Schools comment utiliser :hover pour qu'elles redeviennent en couleur quand la souris passe dessus.

Bonus : ajoute transition: filter 0.5s; pour que le changement soit doux (on étudiera les transitions à la séance 15).

⚠️ Erreurs fréquentes

background-image: images/fond.jpg;
Il faut url("images/fond.jpg")
Mon image de fond n'apparaît pas
La boîte a besoin d'une hauteur (height) ou d'un contenu
L'image de fond se répète en mosaïque
background-size: cover; ou background-repeat: no-repeat;
Le chemin de l'image marche dans le HTML mais pas dans le CSS
Le chemin dans le CSS part du fichier CSS : vérifie s'il faut ../images/…

📚 Vocabulaire

Arrière-plan (background)
Ce qui est derrière le contenu d'une boîte.
Dégradé (gradient)
Un passage progressif d'une couleur à une autre.
cover
L'image remplit toute la zone, quitte à être un peu coupée.
Opacité
Le niveau de transparence : 0 = invisible, 1 = opaque.
Filtre
Un effet appliqué à un élément : flou, gris, sépia…
