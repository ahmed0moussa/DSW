La journée du code au collège

Samedi dernier, 60 élèves ont créé leur premier site web en une seule journée.

Une matinée pour apprendre

Le matin, les élèves ont découvert le HTML et le CSS avec des formateurs. Beaucoup n'avaient jamais écrit une ligne de code. À midi, chacun avait déjà une page avec des titres, des images et des couleurs.

Un après-midi pour créer

L'après-midi, les équipes ont choisi un thème : le sport, la musique, les jeux ou la nature. Voici les thèmes les plus choisis :

  • ⚽ Le sport
  • 🎵 La musique
  • 🎮 Les jeux vidéo
  • 🌿 La nature

Pour aller plus loin
