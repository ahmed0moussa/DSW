Séance 21 · Atelier : carte profil et galerie

Séance atelier ! Tu construis seul(e) deux composants complets en réutilisant tout ce que tu as appris : une carte de profil et une galerie photo responsive. C'est l'entraînement avant le projet final.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, Unsplash, Coolors, Google Fonts
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Réaliser un composant complet à partir d'un modèle, en autonomie.
  • Combiner box model, Flexbox, Grid, responsive, transitions et variables dans une même page.
  • Chercher seul(e) une solution dans la documentation (W3Schools How To, MDN).

🔁 Rappel

Un site multi-pages : index.html, un seul css/style.css, le même menu partout, des variables CSS dans :root.

📒 La note : ce qu'il faut comprendre

1Méthode : du modèle au code

Avant de coder, on observe le modèle et on le découpe en boîtes :

  • 1. Je dessine les boîtes sur papier (qui est dans qui ?).
  • 2. J'écris tout le HTML d'abord, sans CSS.
  • 3. J'ajoute le CSS de l'extérieur vers l'intérieur : la page, puis la carte, puis les détails.
  • 4. Je teste en mode téléphone.
  • 5. J'ajoute les effets (:hover, transitions) à la fin.

💡 Astuce : Bloqué(e) ? Ouvre F12 sur l'exemple de la séance et inspecte l'élément qui te pose problème. Lire le code des autres, c'est comme ça qu'apprennent les développeurs !

2La carte profil : la structure

HTML
<article class="profil">
  <div class="profil-haut"></div>
  <img class="avatar" src="moi.jpg" alt="Ma photo">
  <h2>Sara</h2>
  <p class="metier">Future développeuse web</p>
  <p>J'aime créer des pages jolies et utiles.</p>
  <ul class="competences">
    <li>HTML</li><li>CSS</li><li>Design</li>
  </ul>
  <a class="bouton" href="#">Me contacter</a>
</article>

💡 Astuce : L'avatar qui « déborde » sur le bandeau de couleur : une margin-top négative (ex. margin-top: -50px).

3La galerie : la structure

HTML
<section class="galerie">
  <figure>
    <img src="images/photo1.jpg" alt="…">
    <figcaption>Légende</figcaption>
  </figure>
  <!-- … 6 figures en tout … -->
</section>
CSS
.galerie {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 15px;
}

💡 Astuce : <figure> et <figcaption> sont les balises sémantiques pour une image avec sa légende.

👉 Ouvre l'exemple complet de la séance, puis fais clic droit → Inspecter pour voir son code.

🛠️ Exercices pas à pas

Exercice 1 · La carte profil : HTMLmoyen

  1. Crée seance21/index.html et style.css. Déclare tes variables (couleurs Coolors, police Google Fonts).
  2. Écris le HTML de ta carte profil (avec TES informations : photo ou avatar, prénom, passion, 3 compétences, bouton).
  3. Vérifie le HTML sans CSS : tout le contenu doit être là et dans le bon ordre.

Exercice 2 · La carte profil : CSSmoyen

  1. Centre la carte dans la page (Flexbox sur le body ou margin: 0 auto). Largeur max 340px, coins arrondis, ombre.
  2. Bandeau de couleur en haut, avatar rond avec bordure blanche et margin-top négative.
  3. Compétences en badges côte à côte (display: flex; flex-wrap: wrap; gap).
  4. Au :hover, la carte monte légèrement (transform + transition).

Exercice 3 · La galeriedifficile

  1. Sous la carte, crée une galerie de 6 photos avec <figure> et <figcaption>.
  2. Grille responsive avec auto-fit et minmax. Images de même hauteur avec object-fit: cover.
  3. Au survol : l'image zoome et la légende change de couleur.
  4. Teste à 375px, 768px et 1280px de large (F12).

🏆 Défi bonus : La légende cachée

Dans la galerie, cache la légende (opacity: 0) et place-la par-dessus l'image en bas (position: absolute). Au survol de la photo, elle apparaît en glissant (transform + transition).

Bonus : ajoute une 2e carte profil (un ami, un personnage) et mets les cartes côte à côte sur ordinateur et l'une sous l'autre sur téléphone.

⚠️ Erreurs fréquentes

Je commence le CSS avant d'avoir fini le HTML
HTML complet d'abord, CSS ensuite
Mon avatar est carré et déformé
width = height + object-fit: cover + border-radius: 50%
La légende absolute part en haut de la page
La <figure> doit avoir position: relative
Je reste bloqué(e) 20 minutes sans rien dire
Je cherche 5 minutes (W3Schools, F12), puis je demande à un voisin ou au formateur
