Séance 02 · Ma première page HTML

Tu sais maintenant ce qu'est un site web et tu as installé VS Code. Aujourd'hui tu écris ta toute première vraie page HTML !

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code + extension Live Server, navigateur Chrome
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Expliquer ce qu'est une balise et un élément HTML.
  • Créer un fichier index.html avec la structure de base (le squelette).
  • Utiliser les titres <h1> à <h6>, les paragraphes <p> et les commentaires.

🔁 Rappel

Un site web est fait de fichiers rangés sur un serveur. Le navigateur les lit et les affiche. Le HTML donne la structure, le CSS la décoration, le JavaScript l'action. On écrit le code dans VS Code et on voit le résultat avec Live Server.

📒 La note : ce qu'il faut comprendre

1Une page web = un fichier .html

Une page web est un simple fichier texte qui se termine par .html. Le navigateur lit ce fichier et l'affiche joliment.

HTML veut dire HyperText Markup Language : un langage de balisage. On ne fait pas de calculs : on « étiquette » chaque morceau de texte pour dire au navigateur ce que c'est (un titre, un paragraphe, une image…).

💡 Astuce : La page d'accueil d'un site s'appelle presque toujours index.html.

2Une balise HTML

Le HTML utilise des balises. Une balise s'ouvre avec <nom> et se ferme avec </nom>. Ce qui est entre les deux est le contenu.

Ensemble (ouverture + contenu + fermeture), cela s'appelle un élément.

HTML
<p>Bonjour, je suis un paragraphe.</p>
Résultat

💡 Astuce : N'oublie jamais le / dans la balise fermante : </p>.

3Le squelette d'une page

Toute page HTML commence par la même structure. Dans VS Code, tape ! puis appuie sur Entrée : le squelette s'écrit tout seul !

<head> contient les informations invisibles (titre de l'onglet, langue…). <body> contient tout ce qui est visible sur la page.

HTML
<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ma première page</title>
  </head>
  <body>
    <!-- Tout ce qui est visible va ici -->
  </body>
</html>

💡 Astuce : <meta charset="UTF-8"> permet d'afficher correctement les accents (é, è, à).

4Les titres et les paragraphes

Il existe 6 niveaux de titres : <h1> est le plus important (un seul par page), <h6> le plus petit.

<p> sert à écrire un paragraphe. <br> fait un retour à la ligne (c'est une balise orpheline : elle n'a pas de fermeture).

HTML
<h1>Mon titre principal</h1>
<h2>Un sous-titre</h2>
<h3>Un plus petit titre</h3>
<p>Ceci est un paragraphe.<br>Et ceci est la ligne suivante.</p>
Résultat

5Les commentaires

Un commentaire est une note pour toi (ou pour ton formateur). Le navigateur ne l'affiche pas.

Raccourci dans VS Code : sélectionne une ligne puis Ctrl + /.

HTML
<!-- Ceci est un commentaire : il est invisible -->
<p>Ceci est visible.</p>
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Préparer mon espace de travailfacile

  1. Dans ton dossier formation-web (créé à la séance 1), crée un dossier seance02.
  2. Ouvre VS Code → Fichier → Ouvrir le dossier → choisis formation-web.
  3. Crée un fichier index.html dans seance02.
  4. Tape ! puis Entrée pour écrire le squelette. Change le <title> en « Ma première page ».
  5. Clic droit dans le fichier → Open with Live Server. Ta page s'ouvre dans le navigateur !

Exercice 2 · Ma carte d'identitéfacile

  1. Dans <body>, écris un <h1> avec ton prénom.
  2. Ajoute un <h2>Qui suis-je ?</h2> et un paragraphe <p> qui te présente (âge, ville, école).
  3. Ajoute un <h2>Mes passions</h2> et un paragraphe sur ce que tu aimes.
  4. Enregistre (Ctrl + S) : la page se met à jour toute seule grâce à Live Server.

Exercice 3 · Mon futur métiermoyen

  1. Ajoute un <h2>Plus tard, je veux être…</h2>.
  2. Écris 2 paragraphes : le métier choisi, puis pourquoi tu l'aimes.
  3. Utilise au moins une fois <br> pour couper une ligne.
  4. Ajoute un commentaire <!-- Fin de ma page --> à la fin du <body>.

🏆 Défi bonus : La page « recette de cuisine »

Crée un nouveau fichier recette.html avec la recette de ton plat tunisien préféré (couscous, brik, makroud…).

Utilise un <h1> pour le nom du plat, des <h2> pour « Ingrédients » et « Préparation » et des paragraphes. Utilise au moins 3 niveaux de titres différents.

⚠️ Erreurs fréquentes

J'oublie de fermer une balise : <p>Bonjour
Je ferme toujours : <p>Bonjour</p>
J'écris mon texte dans <head>
Tout le contenu visible va dans <body>
Mon fichier s'appelle index.html.txt ou Index HTML
Nom en minuscules, sans espace, extension .html
Je modifie le fichier mais rien ne change
J'enregistre avec Ctrl + S (le rond blanc sur l'onglet de VS Code = pas enregistré)

📚 Vocabulaire

HTML
HyperText Markup Language : le langage qui décrit la structure d'une page.
Balise
Un mot entre chevrons, comme <p> ou </p>.
Élément
Balise ouvrante + contenu + balise fermante.
Navigateur
Le logiciel qui affiche les pages web (Chrome, Firefox, Edge).
Éditeur de code
Le logiciel où on écrit le code (VS Code).
Balise orpheline
Une balise sans fermeture, comme <br> ou <img>.
