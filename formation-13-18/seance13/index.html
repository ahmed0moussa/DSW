Séance 13 · CSS Grid : la mise en page en grille

Flexbox aligne sur une ligne. CSS Grid organise en lignes ET colonnes à la fois. C'est parfait pour une galerie ou la structure d'une page entière. On commence en jardinant 🥕 !

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : Grid Garden, VS Code, Live Server
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer une grille avec display: grid et grid-template-columns, en utilisant l'unité fr et repeat().
  • Faire prendre plusieurs cases à un élément avec grid-column: span 2 et grid-row.
  • Dessiner la mise en page d'une page avec grid-template-areas.

🔁 Rappel

Flexbox : display: flex sur le parent, justify-content, align-items, flex-wrap, gap, flex: 1 1 250px sur les enfants.

📒 La note : ce qu'il faut comprendre

1Créer une grille

Comme Flexbox, Grid se met sur le parent. On dit combien de colonnes on veut avec grid-template-columns.

L'unité fr (fraction) partage l'espace libre : 1fr 1fr 1fr = 3 colonnes égales. 1fr 2fr = la 2e colonne est 2 fois plus large.

HTML
<div class="grille">
  <div>1fr</div><div>2fr</div><div>1fr</div>
  <div>4</div><div>5</div><div>6</div>
</div>
CSS
.grille {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 8px;
}
.grille div { background: #288b8b; color: white; padding: 12px; border-radius: 6px; }
Résultat

2repeat() et auto-fit

repeat(4, 1fr) = 1fr 1fr 1fr 1fr.

La formule magique : repeat(auto-fit, minmax(150px, 1fr)) → autant de colonnes que possible, chacune d'au moins 150px. La grille devient responsive toute seule !

HTML
<div class="galerie">
  <div>1</div><div>2</div><div>3</div><div>4</div>
  <div>5</div><div>6</div><div>7</div><div>8</div>
</div>
CSS
.galerie {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(110px, 1fr));
  gap: 8px;
}
.galerie div { background: #e67e22; color: white; padding: 20px 0; text-align: center; border-radius: 6px; }
Résultat

💡 Astuce : Réduis la fenêtre de ton navigateur : le nombre de colonnes change automatiquement.

3Prendre plusieurs cases : span

Sur un enfant : grid-column: span 2 → il prend 2 colonnes. grid-row: span 2 → il prend 2 lignes.

On peut aussi donner les lignes de début et de fin : grid-column: 1 / 3 (de la ligne 1 à la ligne 3).

HTML
<div class="grille">
  <div class="large">span 2 colonnes</div>
  <div class="haut">span 2 lignes</div>
  <div>3</div><div>4</div>
</div>
CSS
.grille { display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px; }
.grille div { background: #e3f3f3; padding: 12px; border-radius: 6px; }
.grille .large { grid-column: span 2; background: #fdf0e3; }
.grille .haut { grid-row: span 2; background: #ede7f6; }
Résultat

4grid-template-areas : dessiner sa page

On donne un nom à chaque zone avec grid-area, puis on « dessine » la grille avec des mots. Chaque ligne entre guillemets = une ligne de la grille.

CSS
.page {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "haut  haut"
    "menu  contenu"
    "bas   bas";
  gap: 6px;
}
header { grid-area: haut; }
nav    { grid-area: menu; }
main   { grid-area: contenu; }
footer { grid-area: bas; }
Résultat

💡 Astuce : Flexbox ou Grid ? Flexbox pour aligner sur une direction (un menu, une rangée de boutons). Grid pour une mise en page en 2 dimensions (une galerie, la structure de la page).

🛠️ Exercices pas à pas

Exercice 1 · Ma première grillefacile

  1. Crée seance13/index.html avec une <div class="grille"> qui contient 9 cases numérotées.
  2. Mets display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px;.
  3. Change en 1fr 2fr 1fr, puis en 200px 1fr. Observe.

Exercice 2 · La galerie responsivemoyen

  1. Crée une galerie de 8 photos (sur ton thème préféré) avec object-fit: cover et la même hauteur.
  2. Utilise grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));.
  3. Fais prendre 2 colonnes et 2 lignes à la première photo avec span.

Exercice 3 · La page magazinedifficile

  1. Crée une page avec <header>, <nav>, <main>, <aside> et <footer>.
  2. Dessine sur papier ta mise en page, puis écris-la avec grid-template-areas.
  3. Donne une couleur de fond différente à chaque zone pour vérifier le placement.

🏆 Défi bonus : La grille « bento »

Les sites modernes utilisent des grilles « bento » (comme une boîte à repas japonaise) : des cases de tailles différentes. Crée une grille de 4 colonnes avec 7 cases, certaines en span 2 (largeur ou hauteur).

Et termine les 28 niveaux de Grid Garden !

⚠️ Erreurs fréquentes

Je mets display: grid sur les cases
display: grid va sur le parent
grid-template-areas ne marche pas
Chaque ligne doit avoir le même nombre de mots, et chaque zone un grid-area
J'écris grid-template-column sans s
C'est grid-template-columns (avec un s)
Mes images n'ont pas la même hauteur
Je leur donne height + object-fit: cover et width: 100%

📚 Vocabulaire

Grid
Un système de CSS pour organiser en lignes et en colonnes.
fr
Fraction de l'espace libre.
repeat()
Répète une taille de colonne plusieurs fois.
minmax()
Une taille minimum et une taille maximum.
span
Faire prendre plusieurs cases à un élément.
grid-area
Le nom d'une zone de la grille.
