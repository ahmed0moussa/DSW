📒 La note : ce qu'il faut comprendre

1Même HTML, nouveau style

Le HTML, c'est le contenu. Le CSS, c'est l'apparence. On peut complètement changer l'apparence d'une page sans toucher au contenu : c'est la grande force du CSS.

Compare l'exemple de la séance 7 et celui d'aujourd'hui : c'est le même HTML, avec une seule ligne en plus dans le <head> !

HTML
<head>
  …
  <link href="https://fonts.googleapis.com/css2?family=…" rel="stylesheet">
  <link rel="stylesheet" href="style.css">
</head>

2Le cahier des charges du style

  • Une palette de 4-5 couleurs choisie sur Coolors, écrite en HEX.
  • 2 polices Google Fonts (titres / texte), tailles en rem, line-height confortable.
  • * { box-sizing: border-box; } et un contenu centré avec max-width + margin: 0 auto.
  • Un <header> avec une image de fond + voile sombre (dégradé) pour lire le texte.
  • Un menu avec des liens en inline-block (comme des boutons) et position: sticky.
  • Les sections comme des cartes : fond blanc, padding, border-radius, box-shadow.
  • Images arrondies avec object-fit, un tableau stylé, un formulaire lisible.
  • Un badge ou une étiquette en position: absolute.

3L'ordre pour écrire le CSS

Écris ton CSS du plus général au plus précis, et sépare les parties avec des commentaires :

CSS
/* 1. Base : toute la page */
* { box-sizing: border-box; }
body { … }

/* 2. Texte : titres, paragraphes, liens */
h1, h2 { … }

/* 3. Les grandes zones */
header { … }
nav a { … }
main section { … }

/* 4. Les détails */
table { … }
.badge { … }

💡 Astuce : Les commentaires CSS s'écrivent /* … */ (pas <!-- --> comme en HTML).

4Déboguer avec F12

  • Clic droit sur l'élément qui ne va pas → Inspecter.
  • Dans Styles : une propriété barrée = elle est remplacée par une autre règle plus précise ou écrite plus bas.
  • Un petit triangle jaune ⚠ = la propriété ou la valeur est mal écrite.
  • Dans Computed, le schéma de la boîte montre les vraies valeurs de margin, border, padding.
  • Teste une valeur en direct dans F12, puis recopie-la dans ton fichier style.css (F12 ne l'enregistre pas).

🛠️ Exercices pas à pas

Exercice 1 · Je prépare mon stylefacile

  1. Copie ton dossier seance07 (page + images) et renomme la copie seance13.
  2. Choisis une palette sur Coolors et 2 polices sur Google Fonts. Note les codes.
  3. Crée style.css, relie-le, ajoute le <link> Google Fonts avant ton CSS.
  4. Écris les 4 commentaires de l'ordre de travail (base, texte, zones, détails).

Exercice 2 · J'habille ma pagemoyen

  1. Base : box-sizing, police et couleurs du body, main centré avec max-width.
  2. Texte : titres avec ta police de titre, liens avec leurs états (LoVe HAte).
  3. Header : image de fond cover + voile sombre, texte blanc centré.
  4. Menu : liens en inline-block avec padding et coins arrondis, menu en position: sticky.
  5. Sections en cartes : fond, padding, border-radius, box-shadow, margin entre elles.
  6. Détails : images arrondies, tableau (bordures, padding, en-tête coloré), formulaire, badge en absolute.

Exercice 3 · La chasse aux erreursmoyen

  1. Avec F12, trouve une propriété barrée dans ta page et explique pourquoi elle est barrée.
  2. Change en direct dans F12 le padding de tes cartes jusqu'à ce qu'il te plaise, puis recopie la valeur dans style.css.
  3. Vérifie que ton menu reste en haut quand tu fais défiler la page.

🏆 Défi bonus : Deux thèmes, un seul HTML

Crée un deuxième fichier style-nuit.css avec un thème sombre (fond foncé, texte clair). Change juste le nom du fichier dans le <link> : toute ta page change d'ambiance !

⚠️ Erreurs fréquentes

Mon CSS ne s'applique pas du tout
Vérifier le <link rel="stylesheet" href="style.css"> et le nom exact du fichier
Une propriété est barrée dans F12
Une autre règle plus précise (ou écrite plus bas) la remplace
Le texte est illisible sur l'image du header
Ajouter un voile : linear-gradient(rgba(0,0,0,0.6), rgba(0,0,0,0.3)), url(…)
Je modifie dans F12 et je perds tout en rechargeant
F12 sert à tester : je recopie la bonne valeur dans style.css
