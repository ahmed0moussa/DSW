Séance 14 · Flexbox 1 : aligner facilement

Flexbox est l'outil le plus utilisé pour placer des éléments côte à côte, les centrer et les espacer. Aujourd'hui tu l'apprends en jouant avec des grenouilles 🐸 !

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : Flexbox Froggy, VS Code, Live Server
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Transformer une boîte en conteneur flex avec display: flex.
  • Aligner les éléments horizontalement avec justify-content et verticalement avec align-items.
  • Changer la direction (flex-direction), passer à la ligne (flex-wrap) et espacer (gap).

🔁 Rappel

display: block = l'un sous l'autre, inline-block = côte à côte dans la ligne. position sert à placer un élément précis (badge, menu collant).

📒 La note : ce qu'il faut comprendre

1Le parent et les enfants

Flexbox se met sur le parent (le conteneur). Ses enfants directs se placent alors automatiquement en ligne.

HTML
<div class="conteneur">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
CSS
.conteneur {
  display: flex;
}
Résultat

💡 Astuce : Les règles Flexbox s'écrivent sur le parent, pas sur les enfants. C'est l'erreur n°1 !

2justify-content : aligner sur l'axe principal

Par défaut l'axe principal est horizontal (gauche → droite).

  • flex-start : au début (par défaut).
  • center : au centre.
  • flex-end : à la fin.
  • space-between : le premier au début, le dernier à la fin, de l'espace entre.
  • space-around / space-evenly : de l'espace autour de chacun.
CSS
.conteneur { display: flex; justify-content: space-between; }
Résultat

3align-items : aligner sur l'axe secondaire

L'axe secondaire est vertical. Il faut que le conteneur soit plus haut que les éléments pour voir l'effet.

  • stretch : les éléments s'étirent (par défaut).
  • flex-start, center, flex-end : en haut, au centre, en bas.
CSS
.conteneur {
  display: flex;
  justify-content: center;
  align-items: center;   /* centré parfaitement ! */
  height: 120px;
}
Résultat

💡 Astuce : justify-content: center + align-items: center = la façon la plus simple de centrer quelque chose au milieu d'une boîte.

4flex-direction, flex-wrap et gap

  • flex-direction: row (en ligne, par défaut) ou column (en colonne). Attention : en column, les axes s'inversent !
  • flex-wrap: wrap : si il n'y a plus de place, les éléments passent à la ligne.
  • gap: 15px : l'espace entre les éléments (plus simple que des margins).
CSS
.conteneur {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Mes 3 boîtesfacile

  1. Crée seance14/index.html avec une <div class="conteneur"> qui contient 3 <div class="case"> (avec un emoji et un mot chacune).
  2. Donne une couleur, un padding et des coins arrondis aux cases.
  3. Mets display: flex sur le conteneur. Essaie chaque valeur de justify-content une par une.

Exercice 2 · Le centrage parfaitfacile

  1. Crée une <section class="ecran"> de height: 300px avec un fond coloré et un seul bouton dedans.
  2. Centre le bouton horizontalement ET verticalement avec Flexbox.
  3. Change align-items en flex-start puis flex-end pour bien comprendre l'axe vertical.

Exercice 3 · Les vignettes qui passent à la lignemoyen

  1. Crée un conteneur avec 8 vignettes (image + titre) de width: 180px.
  2. Ajoute display: flex, flex-wrap: wrap, gap: 15px et justify-content: center.
  3. Réduis la fenêtre du navigateur : les vignettes doivent passer à la ligne toutes seules.

⚠️ Erreurs fréquentes

Je mets display: flex sur les enfants
display: flex va sur le parent (le conteneur)
align-items: center ne fait rien
Le conteneur doit avoir une hauteur plus grande que ses enfants
En column, justify-content agit à la verticale
Normal : en column, les axes s'inversent
Mes éléments sont tout écrasés
J'ajoute flex-wrap: wrap pour qu'ils passent à la ligne

📚 Vocabulaire

Flexbox
Un système de CSS pour aligner des éléments sur une ligne ou une colonne.
Conteneur flex
Le parent qui a display: flex.
Élément flex
Un enfant direct du conteneur flex.
Axe principal
La direction des éléments (horizontal en row).
Axe secondaire
L'axe perpendiculaire (vertical en row).
gap
L'espace entre les éléments.
