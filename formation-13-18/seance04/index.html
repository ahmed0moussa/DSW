Séance 04 · Listes et tableaux

Pour ranger des informations, on utilise des listes (une à la suite de l'autre) et des tableaux (en lignes et colonnes).

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer une liste à puces <ul> et une liste numérotée <ol>.
  • Construire un tableau avec <table>, <tr>, <th> et <td>.
  • Fusionner des cases avec colspan et organiser un tableau avec <thead> et <tbody>.

🔁 Rappel

Les liens se font avec <a href="…">, les images avec <img src="…" alt="…">. Les images sont rangées dans le dossier images/.

📒 La note : ce qu'il faut comprendre

1La liste à puces <ul>

<ul> (unordered list) = liste sans ordre. Chaque élément est dans un <li> (list item).

HTML
<h3>Dans mon sac</h3>
<ul>
  <li>Un cahier</li>
  <li>Une trousse</li>
  <li>Une gourde</li>
</ul>
Résultat

2La liste numérotée <ol>

<ol> (ordered list) = liste dans l'ordre : un classement, des étapes…

HTML
<h3>Mon top 3 des sports</h3>
<ol>
  <li>Football</li>
  <li>Handball</li>
  <li>Natation</li>
</ol>
Résultat

💡 Astuce : Une liste peut contenir une autre liste : mets un <ul> à l'intérieur d'un <li>.

3Un tableau simple

<table> = le tableau. <tr> (table row) = une ligne. <th> = une case de titre. <td> = une case normale.

On construit un tableau ligne par ligne.

HTML
<table border="1">
  <tr>
    <th>Joueur</th>
    <th>Poste</th>
    <th>Buts</th>
  </tr>
  <tr>
    <td>Amine</td>
    <td>Attaquant</td>
    <td>12</td>
  </tr>
  <tr>
    <td>Rania</td>
    <td>Milieu</td>
    <td>7</td>
  </tr>
</table>
Résultat

💡 Astuce : border="1" sert juste à voir les cases. Dès la séance 8, on fera les bordures en CSS.

4Organiser un tableau : thead, tbody, colspan

<thead> regroupe la ligne des titres, <tbody> le contenu, <tfoot> le bas (total…).

colspan="2" : une case prend la place de 2 colonnes. rowspan="2" : une case prend 2 lignes.

HTML
<table border="1">
  <thead>
    <tr><th>Matière</th><th>Note</th></tr>
  </thead>
  <tbody>
    <tr><td>Maths</td><td>15</td></tr>
    <tr><td>Anglais</td><td>17</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">Moyenne : 16</td></tr>
  </tfoot>
</table>
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Mes listesfacile

  1. Crée seance04/index.html.
  2. Fais une liste à puces de 5 choses que tu aimes manger.
  3. Fais une liste numérotée de ton top 5 des chansons ou des films.
  4. Ajoute un lien sur au moins un élément de la liste (vers YouTube ou Wikipédia).

Exercice 2 · Une liste dans une listemoyen

  1. Crée une liste <ul> « Mes matières » avec 3 matières.
  2. Dans chaque <li>, ajoute une sous-liste <ul> avec 2 chapitres étudiés.
  3. Observe : les puces changent de forme pour la sous-liste.

Exercice 3 · Le tableau de mon équipemoyen

  1. Crée un tableau avec 3 colonnes : Prénom, Sport, Âge.
  2. Utilise <thead> pour la ligne de titres (<th>) et <tbody> pour 4 lignes de données.
  3. Ajoute une 4e colonne « Photo » avec une petite image (width="60") dans chaque ligne.

🏆 Défi bonus : L'emploi du temps

Reproduis l'emploi du temps de ta classe pour 3 jours (lignes = jours, colonnes = heures).

Ajoute une ligne « Pause déjeuner » qui prend toute la largeur grâce à colspan. Bonus : utilise rowspan pour un cours de 2 heures.

⚠️ Erreurs fréquentes

Je mets du texte directement dans <ul> sans <li>
Chaque élément de la liste est dans un <li>
Je mélange l'ordre : <td> en dehors d'un <tr>
Toujours <table> → <tr> → <td>
Une ligne a 4 cases et une autre en a 3
Chaque ligne doit avoir le même nombre de cases (ou utiliser colspan)
J'utilise un tableau pour placer toute ma page
Les tableaux servent aux données ; la mise en page se fera en CSS

📚 Vocabulaire

ul
Unordered list : liste à puces.
ol
Ordered list : liste numérotée.
li
List item : un élément de la liste.
tr
Table row : une ligne du tableau.
th / td
Case de titre / case de donnée.
colspan / rowspan
Fusionner des colonnes / des lignes.
