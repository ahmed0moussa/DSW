Séance 12 · Display et position

Pourquoi certains éléments se mettent les uns sous les autres et d'autres côte à côte ? Et comment coller un menu en haut de l'écran ? Réponse : display et position.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Expliquer la différence entre block, inline et inline-block, et cacher un élément avec display: none.
  • Placer un élément avec position : relative, absolute, fixed, sticky.
  • Gérer la superposition des éléments avec z-index.

🔁 Rappel

On sait mettre des fonds, des dégradés et des filtres. Chaque élément est une boîte avec padding, border et margin.

📒 La note : ce qu'il faut comprendre

1block, inline, inline-block

  • block : prend toute la largeur, commence sur une nouvelle ligne (div, p, h1, section…).
  • inline : reste dans la ligne, on ne peut pas lui donner de width/height (span, a, strong…).
  • inline-block : reste dans la ligne mais accepte width, height et padding. Idéal pour des boutons ou des badges.
HTML
<span class="b">block</span><span class="b">block</span>
<span class="i">inline</span> <span class="i">inline</span>
<p><span class="ib">inline-block</span> <span class="ib">inline-block</span></p>
CSS
.b { display: block; background: #e3f3f3; margin: 4px 0; }
.i { display: inline; background: #fdf0e3; }
.ib { display: inline-block; width: 90px; height: 40px; background: #ede7f6; text-align: center; }
Résultat

2Cacher un élément

  • display: none; → l'élément disparaît complètement (il ne prend plus de place).
  • visibility: hidden; → l'élément est invisible mais garde sa place.

💡 Astuce : display: none est très utilisé avec les media queries (séance 17) pour cacher un élément sur mobile.

3position: relative et absolute

relative : l'élément bouge par rapport à sa place normale avec top, left, right, bottom.

absolute : l'élément se place par rapport au premier parent qui a position: relative. Parfait pour un badge « Nouveau » sur une carte !

HTML
<div style="padding:15px">
<div class="carte">Nouveau jeu : Robot Run
  <span class="badge">NOUVEAU</span>
</div></div>
CSS
.carte { position: relative; width: 200px; height: 120px; background: #e3f3f3; border-radius: 8px; padding: 10px; }
.badge { position: absolute; top: -10px; right: -10px; background: crimson; color: white; padding: 4px 10px; border-radius: 20px; }
Résultat

💡 Astuce : Retiens : parent relative, enfant absolute.

4position: fixed et sticky

  • fixed : l'élément reste collé à l'écran, même quand on fait défiler la page (bouton « retour en haut », bulle de chat).
  • sticky : l'élément défile normalement puis se colle quand il atteint top: 0 (menu qui reste en haut).
HTML
<nav>Je reste en haut</nav>
<p>Fais défiler…</p><p>…encore…</p><p>…le menu reste visible !</p><p>.</p><p>.</p><p>.</p><p>Fin.</p>
CSS
nav {
  position: sticky;
  top: 0;
  background: #288b8b;
}
Résultat

5z-index : qui est au-dessus ?

Quand des éléments positionnés se chevauchent, celui qui a le plus grand z-index passe devant.

HTML
<div class="rouge">z-index 1</div><div class="bleu">z-index 3</div><div class="vert">z-index 2</div>
CSS
div { position: absolute; width: 90px; height: 90px; color: white; padding: 5px; }
.rouge { background: crimson; top: 10px; left: 10px; z-index: 1; }
.bleu { background: #2980b9; top: 40px; left: 50px; z-index: 3; }
.vert { background: #27ae60; top: 70px; left: 90px; z-index: 2; }
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Un menu en inline-blockfacile

  1. Crée seance12/index.html avec un <nav> qui contient 4 liens.
  2. Donne aux liens display: inline-block, un padding, une couleur de fond et des coins arrondis : ce sont des boutons !
  3. Ajoute un long contenu (plusieurs sections) pour pouvoir faire défiler la page.

Exercice 2 · Le menu collantmoyen

  1. Donne au <nav> : position: sticky; top: 0; et une couleur de fond.
  2. Fais défiler la page : le menu doit rester en haut.
  3. Ajoute un lien « ⬆ Haut » en position: fixed en bas à droite (bottom: 20px; right: 20px;) qui renvoie vers #haut.

Exercice 3 · Les badgesmoyen

  1. Crée 3 cartes de jeux (position: relative) avec une image chacune.
  2. Ajoute un <span class="badge"> « -20 % » en position: absolute dans le coin en haut à droite.
  3. Cache une des cartes avec display: none, puis essaie avec visibility: hidden : quelle différence vois-tu ?

🏆 Défi bonus : Le texte sur l'image

Crée une carte photo : l'image prend toute la carte et le titre est posé par-dessus l'image en bas, sur un fond noir transparent (position: absolute; bottom: 0;).

Bonus : ajoute une bulle de chat ronde 💬 en position: fixed en bas à gauche, avec un z-index élevé.

⚠️ Erreurs fréquentes

Mon élément absolute part tout en haut de la page
J'ai oublié position: relative sur le parent
width ne marche pas sur mon <span> ou mon <a>
Ils sont inline : j'ajoute display: inline-block
z-index ne fait rien
Il marche sur les éléments positionnés (relative, absolute, fixed, sticky)
sticky ne colle pas
Il faut aussi top: 0;

📚 Vocabulaire

display
La façon dont un élément s'affiche (block, inline, none…).
Élément bloc
Prend toute la largeur et passe à la ligne.
Élément en ligne
Reste dans la ligne de texte.
position
La façon de placer un élément (relative, absolute, fixed, sticky).
z-index
L'ordre de superposition : plus grand = devant.
