Séance 01 · Le web, les sites et VS Code

Avant d'écrire du code, on comprend ce qu'on va fabriquer : c'est quoi un site web, à quoi ça sert, comment il arrive sur ton écran et de quoi il est fait. Puis tu installes ton outil de travail : VS Code.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant (aucune connaissance)
  • 🧰 Outils : Navigateur Chrome, VS Code, extension Live Server, papier et crayon
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Expliquer avec mes mots ce qu'est Internet, le web, un site web, un serveur et une adresse (URL).
  • Dire de quoi est fait un site : HTML, CSS, JavaScript et des fichiers (images, vidéos).
  • Expliquer à quoi sert VS Code, l'installer et ouvrir mon premier fichier avec Live Server.

🔁 Rappel

C'est la toute première séance ! Tu n'as besoin d'aucune connaissance. Il faut juste savoir utiliser une souris, un clavier et un navigateur pour aller sur un site.

📒 La note : ce qu'il faut comprendre

1Internet et le web : ce n'est pas pareil !

Internet est un immense réseau : des millions d'ordinateurs, de téléphones et de serveurs reliés entre eux par des câbles (même sous la mer !), des antennes et le Wi-Fi.

Le web (en entier : *World Wide Web*, la « toile d'araignée mondiale ») est une des choses qu'on fait sur Internet : visiter des sites. Mais on utilise aussi Internet pour les e-mails, les jeux en ligne, les appels vidéo…

💡 Astuce : Imagine une ville : Internet = les routes, le web = les magasins et les maisons au bord des routes. Les routes servent à aller voir les magasins, mais aussi à autre chose.

2C'est quoi un site web ? À quoi ça sert ?

Un site web est un ensemble de pages reliées entre elles par des liens. Chaque page est un fichier. Exemples : Wikipédia, YouTube, le site de ton école ou d'un club.

Un site sert à :

  • S'informer : actualités, météo, horaires de bus.
  • Apprendre : Wikipédia, W3Schools, cours en ligne.
  • Acheter et vendre : boutiques en ligne.
  • Se divertir et partager : vidéos, musique, réseaux sociaux.
  • Présenter quelqu'un ou quelque chose : le site d'un artiste, d'un restaurant, d'une entreprise… ou TON site à la fin de cette formation !

💡 Astuce : Une page web = un seul écran (une seule adresse). Un site web = toutes les pages ensemble.

3Comment une page arrive sur mon écran ?

Les fichiers d'un site sont rangés sur un serveur : un ordinateur allumé jour et nuit, branché à Internet. Ton navigateur (Chrome, Firefox, Edge, Safari) est le programme qui va les chercher et les affiche.

C'est comme au restaurant : tu (le navigateur) passes une commande, le serveur va en cuisine chercher le plat (les fichiers) et te l'apporte à table (ton écran).

Résultat

💡 Astuce : Tout ça se passe en moins d'une seconde ! Le serveur peut être dans un autre pays.

4L'adresse d'une page : l'URL

Chaque page a une adresse unique, l'URL, comme l'adresse d'une maison. Décortiquons https://fr.wikipedia.org/wiki/Tunisie :

  • https:// → le protocole : la façon de communiquer. Le s veut dire sécurisé (cadenas 🔒).
  • fr.wikipedia.org → le nom de domaine : le nom du site. La fin (.org, .com, .tn pour la Tunisie, .fr pour la France) s'appelle l'extension.
  • /wiki/Tunisie → le chemin : quelle page précise on veut dans le site.

💡 Astuce : Pour avoir son site en ligne, il faut un hébergement (une place sur un serveur) et, si on veut, un nom de domaine à soi. À la dernière séance, on mettra ton site en ligne gratuitement !

5De quoi est fait un site web ?

Un site est fabriqué avec 3 langages et des fichiers, comme une maison :

  • HTML = les murs et les pièces : la structure et le contenu (titres, textes, images, liens). Fichiers .html.
  • CSS = la peinture et la décoration : les couleurs, les tailles, la place des éléments. Fichiers .css.
  • JavaScript = l'électricité : ce qui réagit et bouge (un menu qui s'ouvre, un jeu). Fichiers .js. On le verra après cette formation.
  • Les médias : images (.jpg, .png), vidéos (.mp4), sons (.mp3), polices…
Résultat

💡 Astuce : À gauche : la même page avec seulement du HTML. À droite : avec du CSS. Le contenu est le même, seul le style change !

6Regarder le code d'un vrai site

Tous les sites que tu visites sont écrits en HTML et CSS. Tu peux voir leur code :

  • Ctrl + U : affiche le code source HTML de la page.
  • F12 (ou clic droit → Inspecter) : ouvre les outils de développement. Tu vois le HTML à gauche et le CSS à droite, et tu peux même les modifier en direct !

💡 Astuce : Pas de panique : ce que tu modifies avec F12 change seulement sur ton écran, pendant quelques minutes. Tu ne casses pas le vrai site. Recharge la page (F5) et tout revient.

7Qui fabrique les sites ?

  • Le développeur front-end : il code ce qu'on voit (HTML, CSS, JavaScript). C'est ce que tu vas apprendre !
  • Le développeur back-end : il code ce qui se passe sur le serveur (comptes, mots de passe, bases de données).
  • Le web designer (UX/UI) : il dessine les maquettes, choisit les couleurs et rend le site facile à utiliser.

💡 Astuce : Ces métiers recrutent beaucoup, en Tunisie comme à l'étranger, et on peut souvent les faire à distance.

8VS Code : c'est quoi et pourquoi l'utiliser ?

Pour écrire du code, il faut un éditeur de code. On utilise Visual Studio Code (VS Code) : il est gratuit, créé par Microsoft, et c'est l'éditeur le plus utilisé par les développeurs dans le monde.

Pourquoi pas Word ? Word ajoute de la mise en forme cachée et enregistre en .docx : le navigateur ne peut pas le lire. Et le Bloc-notes marche, mais il ne t'aide pas du tout.

VS Code, lui, t'aide beaucoup :

  • Il colore le code : on repère vite les balises et les erreurs.
  • Il complète ce que tu écris (autocomplétion) et ferme les balises tout seul.
  • Avec ! + Entrée, il écrit tout le squelette d'une page HTML (c'est Emmet).
  • On peut ajouter des extensions, comme Live Server qui affiche ta page et la recharge à chaque enregistrement.
  • Il range tous les fichiers d'un projet dans l'explorateur à gauche.

9L'écran de VS Code et les raccourcis

  • Ctrl + S : enregistrer (le rond ● sur l'onglet veut dire « pas enregistré »).
  • Ctrl + Z : annuler. Ctrl + Y : refaire.
  • Ctrl + / : mettre une ligne en commentaire.
  • Alt + Shift + F : ranger (indenter) le code proprement.
  • Ctrl + B : cacher ou afficher l'explorateur.

10Installer VS Code et Live Server

  • 1. Télécharge VS Code sur code.visualstudio.com et installe-le (bouton « Suivant » partout).
  • 2. Dans VS Code, clique sur l'icône Extensions (les 4 carrés à gauche), cherche Live Server (de Ritwick Dey) et clique sur Install.
  • 3. Active l'enregistrement automatique : menu Fichier → Enregistrement automatique (*Auto Save*).
  • 4. Dans Windows, affiche les extensions des fichiers : Explorateur de fichiers → Affichage → coche Extensions de noms de fichiers. Comme ça tu vois .html à la fin du nom.

💡 Astuce : VS Code peut être en français : extension French Language Pack. Mais les mots du code (balises, propriétés) restent toujours en anglais.

🛠️ Exercices pas à pas

Exercice 1 · Le détective du webfacile

  1. Ouvre 3 sites que tu connais (ex. Wikipédia, un site de sport, le site de ton école).
  2. Pour chacun, note sur une feuille : le nom de domaine, l'extension (.com, .tn…) et si l'adresse commence par https (cadenas 🔒).
  3. Sur un des sites, appuie sur Ctrl + U. Cherche avec Ctrl + F le mot <img : tu viens de trouver une image dans le code HTML !
  4. Cherche aussi le mot .css : quel est le nom d'un fichier CSS du site ?

Exercice 2 · Je transforme Wikipédia (sans rien casser)facile

  1. Va sur la page Wikipédia de ta ville.
  2. Fais clic droit sur le grand titre → Inspecter. La ligne du titre est surlignée dans le code.
  3. Double-clique sur le texte du titre dans le code et remplace-le par ton prénom. Appuie sur Entrée : le titre change sur la page !
  4. Dans la partie Styles à droite, change une couleur. Puis appuie sur F5 : tout revient comme avant. Tu as compris : le site est fait de HTML et de CSS !

Exercice 3 · J'installe et je découvre VS Codemoyen

  1. Installe VS Code et l'extension Live Server (voir la notion 10). Active l'enregistrement automatique.
  2. Crée sur le bureau un dossier formation-web (tout en minuscules, sans espace), et dedans un dossier seance01.
  3. Dans VS Code : Fichier → Ouvrir le dossier → choisis formation-web. Dans l'explorateur, crée le fichier seance01/bonjour.html.
  4. Écris dedans : <h1>Bonjour, je m'appelle …</h1> (avec ton prénom).
  5. Clic droit dans le fichier → Open with Live Server (ou le bouton Go Live en bas). Ta première page s'affiche dans le navigateur. Bravo, tu viens de créer une page web ! 🎉
  6. Change le texte et regarde la page se mettre à jour toute seule.

📚 Vocabulaire

Internet
Le réseau mondial qui relie les ordinateurs.
Web
L'ensemble des sites qu'on visite sur Internet.
Site web
Un ensemble de pages reliées par des liens.
Serveur
Un ordinateur toujours allumé qui garde les fichiers des sites et les envoie.
Navigateur
Le programme qui va chercher les pages et les affiche (Chrome, Firefox…).
URL
L'adresse d'une page, ex. https://fr.wikipedia.org/wiki/Tunisie.
Nom de domaine
Le nom du site dans l'adresse, ex. wikipedia.org.
Hébergement
La place louée (ou gratuite) sur un serveur pour mettre son site.
Éditeur de code
Le programme où on écrit le code : VS Code.
Extension
1) la fin d'un nom de fichier (.html) ; 2) un petit module ajouté à VS Code (Live Server).
