Séance 19 · Les animations CSS

Une transition se déclenche au survol. Une animation peut se lancer toute seule, se répéter à l'infini et avoir plusieurs étapes. Aujourd'hui tu crées des chargements, des rebonds et une bannière animée.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, Animista

🎯 Objectif : à la fin de la séance, je saurai…

  • Décrire les étapes d'une animation avec @keyframes (from/to ou des pourcentages).
  • Lancer une animation avec animation-name, animation-duration, animation-iteration-count…
  • Utiliser le raccourci animation et décaler des animations avec animation-delay.

🔁 Rappel

transition rend un changement doux (au :hover). transform déplace (translate), agrandit (scale) et tourne (rotate).

📒 La note : ce qu'il faut comprendre

1@keyframes : les étapes

On donne un nom à l'animation et on décrit ses étapes. from = le début, to = la fin.

On peut aussi utiliser des pourcentages : 0%, 50%, 100%…

HTML
<div class="balle"></div>
CSS
@keyframes rebond {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-40px); }
  100% { transform: translateY(0); }
}
.balle {
  width: 50px; height: 50px; border-radius: 50%;
  background: #e67e22; margin-top: 50px;
  animation: rebond 1s infinite;
}
Résultat

2Les propriétés d'animation

  • animation-name : le nom des @keyframes.
  • animation-duration : la durée (2s).
  • animation-iteration-count : combien de fois (3, ou infinite pour toujours).
  • animation-delay : attendre avant de commencer (0.5s).
  • animation-direction: alternate : aller puis revenir.
  • animation-timing-function : la vitesse (linear, ease-in-out…).
CSS
/* Le raccourci : nom durée vitesse délai répétition direction */
.element {
  animation: glisse 2s ease-in-out 0.5s infinite alternate;
}

3Le chargement en 3 points

La même animation sur 3 points, avec un animation-delay différent pour chacun : ils sautent l'un après l'autre !

HTML
<div class="points">
  <div class="point"></div>
  <div class="point"></div>
  <div class="point"></div>
</div>
CSS
.points { display: flex; gap: 8px; padding-top: 30px; }
.point { width: 16px; height: 16px; border-radius: 50%; background: #288b8b;
         animation: saut 0.6s infinite alternate; }
.point:nth-child(2) { animation-delay: 0.2s; }
.point:nth-child(3) { animation-delay: 0.4s; }
@keyframes saut { to { transform: translateY(-20px); } }
Résultat

4Animer les couleurs et l'apparition

HTML
<h2 class="titre">Bienvenue !</h2>
CSS
@keyframes arc-en-ciel {
  0%   { background: #288b8b; }
  50%  { background: #8e44ad; }
  100% { background: #e67e22; }
}
@keyframes apparition {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.titre { color: white; padding: 14px; border-radius: 8px;
         animation: arc-en-ciel 3s infinite alternate, apparition 1s; }
Résultat

🛠️ Exercices pas à pas

Exercice 1 · La balle qui rebonditfacile

  1. Crée seance19/index.html avec une <div class="balle"> ronde.
  2. Écris des @keyframes rebond avec 3 étapes (0 %, 50 %, 100 %).
  3. Applique l'animation à la balle : 1s, infinite.
  4. Change la durée et la vitesse (ease-in, linear) et observe.

Exercice 2 · Le chargementmoyen

  1. Crée 3 points côte à côte (Flexbox).
  2. Crée une animation saut et applique-la aux 3 points.
  3. Décale le 2e et le 3e point avec animation-delay et :nth-child().
  4. Bonus : crée un cercle de chargement qui tourne (rotate(360deg), linear, infinite) avec une bordure de couleur seulement en haut.

Exercice 3 · La bannière animéemoyen

  1. Crée une bannière avec un titre et un sous-titre.
  2. Fais apparaître le titre en fondu (opacity de 0 à 1) en glissant du haut.
  3. Fais apparaître le sous-titre 0.5s après le titre (animation-delay).
  4. Ajoute un fond qui change de couleur doucement avec alternate.

🏆 Défi bonus : La scène animée

Crée une petite scène en CSS uniquement : un soleil qui tourne ☀️, des nuages qui traversent l'écran ☁️ (translateX) et une voiture ou un vélo qui roule 🚲.

Bonus : essaie un niveau de CSS Battle pour t'entraîner à dessiner des formes en CSS.

⚠️ Erreurs fréquentes

Mon animation ne démarre pas
Le nom dans animation doit être exactement celui des @keyframes
J'oublie la durée : animation: rebond infinite;
Il faut une durée : animation: rebond 1s infinite;
L'animation saute brusquement à la fin
J'ajoute alternate ou une étape 100% égale à 0%
Trop d'animations : la page est fatigante
J'anime seulement 1 ou 2 éléments importants

📚 Vocabulaire

Animation
Un changement de style automatique, en plusieurs étapes.
@keyframes
La règle qui décrit les étapes d'une animation.
infinite
L'animation se répète sans fin.
delay
Le temps d'attente avant le début.
alternate
L'animation va puis revient.
