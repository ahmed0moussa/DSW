Séance 23 · Projet final 2/3 : construire

Ta maquette est prête et ton dossier aussi. Aujourd'hui tu construis : tout le HTML de tes pages, puis le CSS de base qui donne déjà son identité à ton site.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Projet
  • 🧰 Outils : VS Code, Live Server, F12, Validateur W3C
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Écrire le HTML complet et sémantique de toutes les pages de mon site.
  • Écrire le CSS de base : réglages généraux, header, menu, footer, avec mes variables.
  • Construire la page d'accueil en suivant ma maquette.

🔁 Rappel

Séance 22 : cahier des charges validé, maquette, dossier du projet avec les pages, le même header et footer, et les variables :root dans css/style.css.

📒 La note : ce qu'il faut comprendre

1D'abord tout le HTML

On écrit le contenu de toutes les pages avant de passer au style. Comme ça, on voit tout de suite s'il manque quelque chose.

  • Balises sémantiques : header, nav, main, section, article, footer.
  • Un seul <h1> par page, des <h2> pour les parties.
  • Les vrais textes (pas de Lorem ipsum) et toutes les images avec un alt.
  • Des class bien nommées pour le CSS : .banniere, .cartes, .carte, .galerie…

💡 Astuce : Une page HTML sans CSS doit déjà être compréhensible et bien rangée. Si c'est le cas, ton HTML est bon !

2Puis le CSS de base

Ensuite on style ce qui est commun à toutes les pages : c'est là qu'on gagne le plus de temps.

  • 1. Les variables :root (déjà prêtes) et les réglages de base : *, body, img, liens, titres.
  • 2. Le header et la navbar en Flexbox, le lien actif.
  • 3. Le footer.
  • 4. La page d'accueil : bannière, cartes ou sections.
CSS
/* 1. Variables */
:root { --principale: #288b8b; --accent: #e67e22; }

/* 2. Base */
* { box-sizing: border-box; }
body { margin: 0; font-family: var(--police); }
img { max-width: 100%; }

/* 3. Header et menu */
header { display: flex; justify-content: space-between; align-items: center; }
nav a.actif { border-bottom: 3px solid var(--accent); }

3Avancer sans se perdre

  • Enregistre et regarde le résultat après chaque règle CSS.
  • Garde ta maquette sous les yeux.
  • Quand quelque chose ne marche pas : F12 → Inspecter avant d'appeler le formateur.
  • Note dans un commentaire /* À FAIRE : … */ ce que tu n'as pas fini.

💡 Astuce : Le projet est noté avec la grille de la séance 24. Ouvre-la pour savoir ce qui compte le plus !

🛠️ Exercices pas à pas

Exercice 1 · Le HTML de toutes les pagesmoyen

  1. Remplis le <main> de chaque page avec tes vrais textes et images, en suivant ta maquette.
  2. Ajoute les class dont tu auras besoin pour le CSS.
  3. Passe chaque page dans le validateur W3C et corrige les erreurs.

Exercice 2 · Le CSS communmoyen

  1. Écris les réglages de base avec tes variables : box-sizing, body, img, titres, liens.
  2. Style le header et le menu en Flexbox, avec un style pour le lien actif.
  3. Style le footer. Vérifie que le header et le footer sont identiques sur toutes les pages.

Exercice 3 · La page d'accueildifficile

  1. Construis la bannière (image de fond ou dégradé, titre, bouton).
  2. Construis les cartes ou les sections de l'accueil en Flexbox ou Grid.
  3. Compare avec ta maquette et ajuste les espacements avec F12.

🏆 Défi bonus : Prendre de l'avance

Commence le CSS des autres pages et teste déjà ton site en mode téléphone (F12 → Ctrl + Shift + M).

⚠️ Erreurs fréquentes

Je passe 1 heure sur la bannière
Je fais d'abord tout simplement, je peaufine à la séance 24
Le header est différent sur chaque page
Je copie exactement le même <header> et j'utilise un seul fichier CSS
Le style marche sur l'accueil mais pas sur les autres pages
Chaque page doit avoir le <link> vers css/style.css
Je mets les couleurs en dur partout
J'utilise mes variables : var(--principale)

📚 Vocabulaire

Composant commun
Une partie présente sur toutes les pages (header, menu, footer).
Lien actif
Le lien du menu de la page où l'on se trouve.
Itération
Avancer par petites étapes en vérifiant à chaque fois.
