Séance 08 · Mon premier CSS : sélecteurs et couleurs

Le HTML, c'est la structure. Le CSS, c'est le style ! Aujourd'hui tu donnes des couleurs à ta page et tu apprends à viser exactement l'élément que tu veux modifier.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, HTML Color Codes, CSS Diner
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Écrire une règle CSS : sélecteur, propriété, valeur.
  • Relier un fichier style.css à ma page avec <link>.
  • Viser des éléments par balise, par .classe et par #id, et utiliser des couleurs en nom, HEX et RGB.

🔁 Rappel

Une page bien structurée utilise <header>, <nav>, <main>, <section>, <article>, <footer>. <div> et <span> servent à regrouper.

📒 La note : ce qu'il faut comprendre

1Une règle CSS

Une règle CSS dit : « Qui je modifie { quoi : comment ; } ».

Le sélecteur choisit les éléments. La propriété dit ce qu'on change. La valeur dit comment. Chaque ligne finit par ;.

HTML
<h1>Mon titre stylé</h1>
CSS
h1 {
  color: white;
  background-color: teal;
}
Résultat

23 façons d'ajouter du CSS

  • En ligne : <p style="color: red;"> → à éviter, c'est difficile à modifier.
  • Interne : dans une balise <style> dans le <head> → pour une seule page.
  • Externe : dans un fichier style.css relié avec <link> → la meilleure façon : un seul fichier pour tout le site !
HTML
<head>
  <meta charset="UTF-8">
  <title>Ma page</title>
  <link rel="stylesheet" href="style.css">
</head>

💡 Astuce : Si ton CSS ne marche pas, vérifie d'abord le chemin dans href : le fichier style.css est-il bien dans le même dossier ?

3Les sélecteurs : balise, classe, id

  • p { } → tous les paragraphes.
  • .important { } → tous les éléments qui ont class="important" (un point devant). Une classe peut être utilisée plusieurs fois.
  • #titre { } → l'élément qui a id="titre" (un dièse devant). Un id est unique dans la page.
HTML
<h2 id="titre">Les règles du club</h2>
<p>Arriver à l'heure.</p>
<p class="important">Porter une tenue de sport.</p>
<p>Ranger le matériel.</p>
<p class="important">Respecter les autres.</p>
CSS
p { color: gray; }
.important { color: crimson; font-weight: bold; }
#titre { color: teal; }
Résultat

4Les couleurs

Il y a plusieurs façons d'écrire une couleur :

  • Nom en anglais : red, teal, orange… (140 noms existent).
  • HEX : #288b8b (le plus utilisé). Copie-le sur htmlcolorcodes.com.
  • RGB : rgb(40, 139, 139) = quantité de Rouge, Vert, Bleu de 0 à 255.
  • RGBA : rgba(0, 0, 0, 0.5) = avec de la transparence (0 = invisible, 1 = opaque).
HTML
<div class="a">orange</div>
<div class="b">#288b8b</div>
<div class="c">rgb(142, 68, 173)</div>
<div class="d">rgba(..., 0.4)</div>
CSS
.a { background-color: orange; }
.b { background-color: #288b8b; }
.c { background-color: rgb(142, 68, 173); }
.d { background-color: rgba(142, 68, 173, 0.4); }
div { color: white; padding: 8px; margin: 4px; }
Résultat

5Grouper et combiner

h1, h2 { } : la virgule applique la règle à plusieurs sélecteurs.

nav a { } : l'espace veut dire « les <a> qui sont dans un <nav> ».

HTML
<h1>Titre</h1>
<h2>Sous-titre</h2>
<nav><a href="#">Lien du menu</a></nav>
<a href="#">Lien en dehors du menu</a>
CSS
h1, h2 { font-family: Arial; color: navy; }
nav a { color: orange; }
Résultat

💡 Astuce : Si deux règles se contredisent, c'est la plus précise qui gagne : #id > .classe > balise. À précision égale, la dernière écrite gagne (c'est la cascade).

🏆 Défi bonus : La palette Coolors

Va sur coolors.co, appuie sur la barre espace jusqu'à trouver une palette de 5 couleurs que tu aimes.

Utilise uniquement ces 5 couleurs (en HEX) pour toute ta page : fond, titres, texte, liens, encadrés. Bonus : termine les niveaux 7 à 14 de CSS Diner.

⚠️ Erreurs fréquentes

J'oublie le ; à la fin d'une ligne
Chaque déclaration finit par ; sinon la ligne suivante ne marche pas
.important dans le CSS mais class="Important" dans le HTML
Même nom exactement, sans le point dans le HTML : class="important"
J'écris colour ou couleur
Les propriétés sont en anglais américain : color
J'utilise le même id sur plusieurs éléments
Un id est unique ; pour plusieurs éléments j'utilise une class

📚 Vocabulaire

CSS
Cascading Style Sheets : le langage du style.
Sélecteur
La partie qui choisit les éléments à styler (p, .carte, #menu).
Propriété
Ce qu'on modifie (color, background-color…).
Valeur
Comment on le modifie (red, #288b8b, 20px…).
Classe
Un nom que plusieurs éléments peuvent partager. Sélecteur .nom.
Id
Un nom unique pour un seul élément. Sélecteur #nom.
HEX
Code couleur qui commence par # suivi de 6 caractères.
