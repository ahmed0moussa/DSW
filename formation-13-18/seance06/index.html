Séance 06 · Structure sémantique et médias

Un vrai site est découpé en zones : en-tête, menu, contenu, pied de page. Aujourd'hui tu apprends à les nommer correctement et à ajouter une vidéo YouTube.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, YouTube
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Découper une page en zones avec <header>, <nav>, <main>, <section>, <article>, <aside> et <footer>.
  • Comprendre la différence entre <div> (bloc) et <span> (dans une ligne).
  • Intégrer une vidéo YouTube avec <iframe> et un son avec <audio>.

🔁 Rappel

Les formulaires : <form>, <label for> + <input id>, les types (email, number, radio…) et required.

📒 La note : ce qu'il faut comprendre

1Les balises sémantiques

Sémantique veut dire « qui a un sens ». Ces balises disent au navigateur (et à Google) à quoi sert chaque zone.

  • <header> : l'en-tête (logo, titre du site).
  • <nav> : le menu de navigation.
  • <main> : le contenu principal (un seul par page).
  • <section> : une partie de la page avec un thème.
  • <article> : un contenu qui a du sens tout seul (un article de blog, une carte).
  • <aside> : un contenu à côté (encadré, publicité, liens).
  • <footer> : le pied de page (contact, copyright).
HTML
<header>
  <h1>Mon blog voyage</h1>
  <nav>
    <a href="#">Accueil</a> | <a href="#">Destinations</a>
  </nav>
</header>
<main>
  <article>
    <h2>Un week-end à Djerba</h2>
    <p>Plages, poterie et couscous au poisson…</p>
  </article>
  <aside>À lire aussi : Tozeur</aside>
</main>
<footer>© 2026 Mon blog</footer>
Résultat

💡 Astuce : Dans le résultat, chaque zone a une bordure de couleur pour que tu voies le découpage. Sans CSS, ces balises ne changent rien à l'affichage : elles donnent du sens.

2<div> et <span> : les boîtes sans sens

<div> est une boîte qui prend toute la largeur (un bloc). <span> entoure un morceau de texte dans une ligne.

Ils n'ont pas de sens particulier : on les utilise pour regrouper des éléments et leur donner un style en CSS.

HTML
<div>Je suis un bloc div.</div>
<div>Moi aussi, je commence sur une nouvelle ligne.</div>
<p>Un mot <span style="color:red">en rouge</span> dans la phrase.</p>
Résultat

💡 Astuce : Règle d'or : si une balise sémantique existe (<nav>, <footer>…), utilise-la plutôt qu'une <div>.

3Une vidéo YouTube avec <iframe>

Sur YouTube : sous la vidéo, clique sur Partager → Intégrer, puis copie le code <iframe> et colle-le dans ta page.

Une <iframe> affiche une autre page web à l'intérieur de ta page.

HTML
<iframe width="360" height="203"
  src="https://www.youtube.com/embed/UB1O30fR-EE"
  title="Vidéo YouTube"
  allowfullscreen></iframe>

💡 Astuce : Tu peux faire pareil avec Google Maps : Partager → Intégrer une carte.

4Audio et vidéo de ton ordinateur

Pour un fichier qui est dans ton dossier, utilise <audio> ou <video>. L'attribut controls affiche les boutons lecture/pause.

Attention : le fichier doit vraiment exister dans ton dossier (ex. media/musique.mp3).

HTML
<audio controls src="media/musique.mp3"></audio>

<video controls width="320" src="media/clip.mp4"></video>

Exercice 1 · Le plan de ma pagefacile

  1. Sur une feuille, dessine 5 rectangles : header, nav, main, aside, footer.

Vérifie ton code avec le validateur W3C (lien dans les ressources) : essaie d'avoir 0 erreur !

⚠️ Erreurs fréquentes

Je mets plusieurs <main> dans la page
Un seul <main> par page
J'utilise des <div> partout
J'utilise d'abord les balises sémantiques quand elles existent
La vidéo ne s'affiche pas : j'ai copié l'adresse watch?v=
Il faut le code Intégrer avec l'adresse /embed/
Mon audio ne marche pas
Le fichier doit exister dans mon dossier et le chemin src doit être juste

📚 Vocabulaire

Sémantique
Qui donne du sens : la balise dit à quoi sert son contenu.
Bloc
Un élément qui commence sur une nouvelle ligne et prend toute la largeur (div, p, h1).
En ligne (inline)
Un élément qui reste dans la ligne de texte (span, a, strong).
iframe
Une fenêtre qui affiche une autre page dans ma page.
Intégrer (embed)
Mettre un contenu d'un autre site (vidéo, carte) dans ma page.
