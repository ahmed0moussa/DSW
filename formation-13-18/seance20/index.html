Séance 20 · Un site multi-pages et les variables CSS

Un vrai site a plusieurs pages qui partagent le même menu, le même pied de page et le même style. Aujourd'hui tu organises ton premier site complet de 3 pages.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Organiser les fichiers d'un site : index.html, autres pages, dossiers css/ et images/.
  • Relier plusieurs pages entre elles avec le même menu et un seul fichier CSS.
  • Utiliser des variables CSS (:root, --couleur, var()) pour changer tout le thème en une ligne.

🔁 Rappel

On sait tout faire sur une page : structure, texte, boîte, Flexbox, Grid, responsive, transitions et animations.

📒 La note : ce qu'il faut comprendre

1L'organisation des fichiers

La page d'accueil s'appelle toujours index.html : c'est elle qui s'ouvre en premier quand on visite un site.

Schéma
mon-site/
├── index.html        ← la page d'accueil
├── activites.html
├── contact.html
├── css/
│   └── style.css     ← UN seul CSS pour toutes les pages
└── images/
    ├── logo.png
    └── foret.jpg

💡 Astuce : Le chemin vers le CSS depuis une page : href="css/style.css". Depuis le CSS vers une image : url("../images/foret.jpg") (on remonte d'un dossier).

2Le même menu sur toutes les pages

On copie le même <header> et le même <footer> dans chaque page. Seul le contenu de <main> change.

On ajoute une classe actif sur le lien de la page où l'on se trouve, pour que le visiteur sache où il est.

HTML
<!-- dans activites.html -->
<nav>
  <a href="index.html">Accueil</a>
  <a href="activites.html" class="actif">Activités</a>
  <a href="contact.html">Contact</a>
</nav>

3Les variables CSS

Une variable garde une valeur pour la réutiliser partout. On la déclare dans :root (toute la page) avec deux tirets : --nom: valeur;.

On l'utilise avec var(--nom). Pour changer la couleur de tout le site, il suffit de changer une seule ligne !

HTML
<div class="carte">
  <h2>Randonnée</h2>
  <span class="bouton">Je participe</span>
</div>
CSS
:root {
  --principale: #288b8b;
  --accent: #e67e22;
  --arrondi: 10px;
}
h2 { color: var(--principale); }
.bouton { background: var(--accent); color: white; padding: 10px 18px;
          border-radius: var(--arrondi); display: inline-block; }
.carte { border: 3px solid var(--principale); border-radius: var(--arrondi); padding: 10px; }
Résultat

4Un CSS bien rangé

Pour s'y retrouver, on range le fichier CSS dans le même ordre à chaque fois, avec des commentaires :

  • 1. Les variables (:root).
  • 2. Les réglages de base (*, body, img, a).
  • 3. Les parties communes (header, nav, footer).
  • 4. Les parties de chaque page (cartes, formulaire…).
  • 5. Les media queries à la fin.

🛠️ Exercices pas à pas

Exercice 1 · L'arborescencefacile

  1. Crée le dossier seance20/mon-site/ avec index.html, activites.html, contact.html et les dossiers css/ et images/.
  2. Crée css/style.css et relie-le dans les 3 pages avec <link rel="stylesheet" href="css/style.css">.
  3. Écris le même <header> (logo + menu) et le même <footer> dans les 3 pages.
  4. Clique sur tous les liens du menu : chaque page doit s'ouvrir.

Exercice 2 · Les variables et le style communmoyen

  1. En haut de style.css, déclare dans :root : 2 couleurs, une couleur de fond, une police et un arrondi.
  2. Utilise var(--…) partout dans le CSS (header, liens, boutons, footer).
  3. Ajoute la classe actif sur le bon lien dans chaque page et donne-lui un style.

Exercice 3 · Le contenu des pagesmoyen

  1. Accueil : une bannière + 3 cartes en Flexbox ou Grid.
  2. Activités : un tableau ou une liste de 4 activités avec images.
  3. Contact : un formulaire stylé (:focus, bouton avec transition).
  4. Vérifie les 3 pages en mode téléphone (F12).

🏆 Défi bonus : Le changement de thème

Change seulement les valeurs des variables dans :root pour créer un thème « nuit » (fond sombre, texte clair). Si tout ton site change d'un coup, bravo : tes variables sont bien utilisées !

Bonus : ajoute une page 404.html (page introuvable) amusante avec une animation.

⚠️ Erreurs fréquentes

Mon style ne marche que sur la page d'accueil
Chaque page doit avoir le <link> vers css/style.css
L'image de fond ne s'affiche pas depuis le CSS
Depuis css/style.css, on remonte : url("../images/fond.jpg")
var(principale) ne marche pas
Avec les deux tirets : var(--principale)
Un lien du menu mène à une page blanche ou une erreur
Le nom dans href doit être exactement le nom du fichier

📚 Vocabulaire

Arborescence
L'organisation des dossiers et des fichiers d'un site.
index.html
La page d'accueil, ouverte en premier.
Variable CSS
Une valeur nommée qu'on réutilise : --couleur.
:root
Le sélecteur de la racine de la page, où l'on déclare les variables.
var()
La fonction qui utilise une variable.
Thème
L'ensemble des couleurs, polices et styles d'un site.
