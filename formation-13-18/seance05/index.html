Séance 05 · Les formulaires

Un formulaire permet au visiteur d'écrire et d'envoyer des informations : inscription, contact, sondage… Aujourd'hui tu crées le formulaire d'inscription d'un club.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer un formulaire avec <form>, <label> et <input>.
  • Choisir le bon type de champ : texte, email, nombre, date, radio, case à cocher, liste.
  • Rendre un champ obligatoire avec required et donner un exemple avec placeholder.

🔁 Rappel

Les listes : <ul>/<ol> + <li>. Les tableaux : <table> → <tr> → <th>/<td>.

📒 La note : ce qu'il faut comprendre

1Un champ de texte avec son étiquette

<form> entoure tout le formulaire. <input> est un champ (balise orpheline).

<label> est l'étiquette du champ. Son attribut for doit être identique à l'id du champ : quand on clique sur l'étiquette, le curseur va dans le champ !

HTML
<form>
  <label for="prenom">Ton prénom :</label>
  <input type="text" id="prenom" placeholder="Ex : Sami">
</form>
Résultat

2Les types de champs

L'attribut type change le champ. Le navigateur affiche automatiquement le bon outil (calendrier, couleurs…).

HTML
<input type="email" placeholder="email@exemple.com"><br>
<input type="password" placeholder="Mot de passe"><br>
<input type="number" min="10" max="18" value="14"><br>
<input type="date"><br>
<input type="color" value="#288b8b"><br>
<input type="range" min="0" max="10">
Résultat

3Choisir : radio, checkbox, select

  • radio = un seul choix possible. Tous les boutons du groupe ont le même name.
  • checkbox = plusieurs choix possibles.
  • <select> + <option> = une liste déroulante.
HTML
<p>Niveau :</p>
<input type="radio" id="deb" name="niveau">
<label for="deb">Débutant</label>
<input type="radio" id="conf" name="niveau">
<label for="conf">Confirmé</label>

<p>Activités :</p>
<input type="checkbox" id="robot">
<label for="robot">Robotique</label>
<input type="checkbox" id="web">
<label for="web">Web</label>

<p>Ville :
<select>
  <option>Tunis</option>
  <option>Sfax</option>
  <option>Sousse</option>
</select></p>
Résultat

4Zone de texte, obligatoire et bouton

<textarea> = une grande zone pour écrire un message.

required = le champ est obligatoire : le navigateur bloque l'envoi s'il est vide. Essaie de cliquer sur Envoyer sans rien écrire dans l'exemple de la séance !

<button type="submit"> = le bouton d'envoi.

HTML
<form>
  <label for="msg">Ton message :</label><br>
  <textarea id="msg" rows="3" cols="30" required></textarea><br>
  <button type="submit">Envoyer</button>
</form>
Résultat

💡 Astuce : Pour l'instant le formulaire n'envoie les données nulle part. Pour les recevoir il faut un serveur ou du JavaScript : ce sera pour plus tard !

🛠️ Exercices pas à pas

Exercice 1 · Les informations de basefacile

  1. Crée seance05/index.html avec un <h1>Inscription au club</h1>.
  2. Ajoute un <form> avec : prénom (text), email (email), âge (number entre 10 et 18).
  3. Chaque champ a un <label for="…"> relié à son id. Teste en cliquant sur les étiquettes.
  4. Ajoute un placeholder dans chaque champ.

Exercice 2 · Les choixmoyen

  1. Ajoute 3 boutons radio pour le niveau (Débutant, Moyen, Confirmé) avec le même name.
  2. Ajoute 4 cases à cocher pour les activités du club.
  3. Ajoute une liste déroulante <select> avec 5 villes de Tunisie.

Exercice 3 · Message et envoimoyen

  1. Ajoute un <textarea> « Pourquoi veux-tu t'inscrire ? ».
  2. Rends le prénom, l'email et le message obligatoires avec required.
  3. Ajoute un bouton « Je m'inscris ». Teste : que se passe-t-il si un champ obligatoire est vide ? Et si l'email n'a pas de @ ?

🏆 Défi bonus : Le sondage de la classe

Crée un formulaire de sondage « Ta journée idéale » avec au moins 6 types de champs différents : date, color, range, radio, checkbox, select, textarea…

Organise les questions avec <fieldset> et <legend> (cherche sur W3Schools comment ça marche !).

⚠️ Erreurs fréquentes

Le for du label ne correspond pas à l'id
<label for="age"> va avec <input id="age"> (exactement pareil)
Je peux cocher plusieurs boutons radio en même temps
Tous les radios du groupe doivent avoir le même name
J'écris <input></input>
<input> est orpheline : pas de fermeture
Je mets le bouton en dehors du <form>
Le bouton d'envoi doit être dans le <form>

📚 Vocabulaire

Formulaire
Une zone où le visiteur saisit des informations.
Champ
Une case où l'on écrit ou choisit quelque chose (<input>).
Label
L'étiquette qui explique ce qu'il faut écrire dans le champ.
placeholder
Un exemple écrit en gris dans le champ vide.
required
Rend le champ obligatoire.
name
Le nom de la donnée envoyée. Il regroupe aussi les boutons radio.
