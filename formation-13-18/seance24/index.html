Séance 24 · Projet final 3/3 : finaliser, publier, présenter

Dernière séance ! Tu termines le style de ton site, tu le rends responsive, tu le mets en ligne pour que tout le monde puisse le voir… et tu le présentes à la classe. 🎉

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Projet
  • 🧰 Outils : VS Code, F12, Validateur W3C, Netlify Drop ou GitHub Pages
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Terminer le CSS de toutes mes pages et les rendre responsive.
  • Vérifier mon site : responsive, liens, images, validateur, accessibilité de base.
  • Mettre mon site en ligne et le présenter à l'oral en 3 minutes.

🔁 Rappel

Séance 22 : cahier des charges, maquette, dossier du projet. Séance 23 : HTML de toutes les pages, CSS de base (variables, header, footer, page d'accueil).

📒 La note : ce qu'il faut comprendre

1Ce qu'il reste à faire

  • 1. Finir le CSS des autres pages (cartes, galerie, tableau, formulaire…).
  • 2. Le responsive : @media à la fin du fichier, test à 375px, 768px et 1280px.
  • 3. Les effets : :hover, transitions, une animation (une seule !).
  • 4. La checklist qualité, puis la mise en ligne.

💡 Astuce : Toutes les 15 minutes, regarde ton site en mode téléphone (F12). C'est plus facile de corriger tout de suite qu'à la fin.

2La checklist qualité

  • Tous les liens du menu marchent, sur toutes les pages.
  • Toutes les images s'affichent et ont un alt.
  • Pas de défilement horizontal sur téléphone.
  • Le texte est lisible : assez grand, assez de contraste avec le fond.
  • Le validateur W3C ne trouve pas d'erreur grave.
  • Les fichiers ont des noms en minuscules, sans espace ni accent.

3Mettre son site en ligne

Méthode simple : Netlify Drop. Va sur app.netlify.com/drop, puis glisse le dossier de ton site dans la page. En quelques secondes, tu obtiens une adresse en ligne à partager !

Méthode des pros : GitHub Pages. Crée un compte GitHub, crée un dépôt, envoie tes fichiers (bouton « Add file → Upload files »), puis active Settings → Pages. Ton site sera à l'adresse tonpseudo.github.io/nom-du-depot.

💡 Astuce : Le dossier doit contenir index.html à sa racine, sinon le site ne s'ouvre pas. Avant de publier, demande l'accord d'un adulte et ne mets jamais d'informations personnelles (adresse, téléphone).

4Présenter son site (3 minutes)

  • 1. Le sujet et le public : « Mon site parle de… il est pour… ».
  • 2. La visite : on clique sur chaque page.
  • 3. La partie dont je suis le plus fier / la plus fière, et comment je l'ai codée.
  • 4. Une difficulté et comment je l'ai résolue.
  • 5. Ce que j'aimerais ajouter (peut-être avec JavaScript !).

👉 Ouvre l'exemple complet de la séance, puis fais clic droit → Inspecter pour voir son code.

⏱️ Déroulé de la séance (2 h)

  2. 0:10 – 0:55Exercices 1 et 2 : fin du CSS, responsive et effets. Le formateur passe voir chaque élève.
  3. 0:55 – 1:15Exercice 3 : checklist qualité et mise en ligne.

🛠️ Exercices pas à pas

Exercice 1 · Je finis le CSSmoyen

  1. Termine le style de chaque page, en utilisant tes variables var(--…) pour toutes les couleurs.
  2. Utilise Flexbox ou Grid pour les cartes et la galerie.
  3. Compare chaque page avec ta maquette.

Exercice 2 · Responsive et effetsdifficile

  1. Teste ton site à 375px (téléphone), 768px (tablette), 1280px (ordinateur).
  2. Ajoute les @media nécessaires (menu en colonne, une seule colonne de cartes…).
  3. Ajoute des :hover avec transitions sur les liens, les boutons et les cartes.
  4. Ajoute une animation (une seule !) : apparition du titre, chargement…

Exercice 3 · Vérifier et publiermoyen

  1. Passe la checklist qualité (notion 2) et corrige ce qui ne va pas.
  2. Passe chaque page dans le validateur W3C.
  3. Publie ton site sur Netlify Drop (ou GitHub Pages) et note l'adresse.
  4. Envoie l'adresse à ton formateur et prépare ta présentation de 3 minutes.

🏆 Défi bonus : Et après ?

Ajoute un mode sombre à ton site avec @media (prefers-color-scheme: dark) : tu redéfinis tes variables :root dedans et ton site change selon le réglage du téléphone !

La suite de l'aventure : JavaScript, pour rendre tes pages vraiment interactives (un bouton qui ouvre le menu, un quiz, un jeu…).

⚠️ Erreurs fréquentes

Je passe 40 minutes sur une seule couleur
Je fais d'abord tout le site simplement, je peaufine à la fin
Le site en ligne n'a pas de style
Le dossier css/ doit être envoyé avec les pages, et les chemins sont sensibles aux majuscules
Netlify affiche « Page not found »
Le fichier index.html doit être à la racine du dossier envoyé
Je lis mon code pendant la présentation
Je montre le site, et j'explique avec mes mots une partie du code
