Grille d'évaluation du projet

Voici comment ton projet sera évalué. Lis-la avant de commencer : elle te dit ce qui est important !

📋 Les critères (sur 20)

CritèreCe qu'on regardePoints
PréparationCahier des charges rempli, maquette dessinée/ 2
Structure HTMLBalises sémantiques, un seul h1 par page, images avec alt, code valide/ 4
Organisation3 ou 4 pages reliées, menu commun, un seul CSS, dossiers bien rangés/ 3
Mise en page CSSFlexbox et/ou Grid, box model maîtrisé, variables CSS/ 4
ResponsiveLisible et sans défilement horizontal sur téléphone/ 3
Design et effetsCouleurs et polices cohérentes, hover, transitions, animation/ 2
Présentation oraleClair, 3 minutes, explique une partie du code/ 2
Total/ 20

🌟 Bonus (+1 point chacun, maximum +2)

  • Le site est en ligne (Netlify ou GitHub Pages)
  • Un composant avancé : menu déroulant, galerie avec légende animée, carte qui se retourne…
  • Un mode sombre avec prefers-color-scheme

✅ Checklist avant de rendre

  • Tous les liens du menu marchent sur toutes les pages
  • Toutes les images s'affichent et ont un alt
  • Pas de défilement horizontal à 375px de large
  • Le texte est lisible (taille et contraste)
  • Le validateur W3C ne trouve pas d'erreur grave
  • Les noms de fichiers sont en minuscules, sans espace ni accent
  • Pas d'information personnelle (adresse, téléphone) sur le site
