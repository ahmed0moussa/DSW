Séance 15 · Flexbox 2 : navbar et cartes

Maintenant que tu connais Flexbox, tu construis les deux éléments qu'on trouve sur presque tous les sites : une barre de navigation et une rangée de cartes.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, Flexbox Froggy (révision)
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Construire une barre de navigation avec un logo à gauche et des liens à droite.
  • Créer une rangée de cartes de même hauteur avec Flexbox.
  • Contrôler la taille des éléments avec flex-grow, flex-basis et le raccourci flex.

🔁 Rappel

display: flex sur le parent. justify-content = axe horizontal, align-items = axe vertical. flex-wrap: wrap et gap pour les espacer.

📒 La note : ce qu'il faut comprendre

1La navbar classique

Un <nav> en flex avec justify-content: space-between : le logo part à gauche, la liste de liens à droite.

La liste <ul> est elle aussi en flex pour mettre les liens côte à côte. C'est un flex dans un flex !

HTML
<nav>
  <div class="logo">MonSite</div>
  <ul>
    <li><a href="#">Accueil</a></li>
    <li><a href="#">Projets</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
</nav>
CSS
nav { display: flex; justify-content: space-between; align-items: center; background: #22303c; padding: 10px 16px; }
.logo { color: #e67e22; font-weight: bold; font-size: 20px; }
nav ul { display: flex; gap: 16px; list-style: none; margin: 0; padding: 0; }
nav a { color: white; text-decoration: none; }
Résultat

2flex-grow : qui prend la place libre ?

flex-grow se met sur un enfant. Il dit quelle part de l'espace libre l'élément prend.

flex-grow: 1 sur tous → ils partagent l'espace en parts égales. flex-grow: 2 → cet élément prend 2 parts.

HTML
<div class="boite">
  <div class="un">grow 1</div>
  <div class="deux">grow 2</div>
  <div class="un">grow 1</div>
</div>
CSS
.boite { display: flex; gap: 6px; }
.boite div { background: #288b8b; color: white; padding: 10px; border-radius: 6px; }
.un { flex-grow: 1; }
.deux { flex-grow: 2; }
Résultat

3Le raccourci flex

flex: 1 1 250px; veut dire : je peux grandir (1), je peux rétrécir (1), ma taille de départ est 250px.

Avec flex-wrap: wrap, ça donne des cartes qui remplissent toute la ligne et passent à la ligne quand l'écran est petit. C'est déjà du responsive !

HTML
<div class="cartes">
  <div class="carte">HTML</div>
  <div class="carte">CSS</div>
  <div class="carte">Flexbox</div>
  <div class="carte">Grid</div>
</div>
CSS
.cartes { display: flex; flex-wrap: wrap; gap: 10px; }
.carte { flex: 1 1 150px; background: #e3f3f3; padding: 12px; border-radius: 8px; }
Résultat

4Des cartes de même hauteur

Avec Flexbox, les cartes d'une même ligne ont automatiquement la même hauteur (grâce à align-items: stretch, la valeur par défaut).

Pour coller le bouton en bas de chaque carte : la carte est elle-même en flex-direction: column et le bouton reçoit margin-top: auto.

CSS
.carte {
  display: flex;
  flex-direction: column;
}
.carte .bouton {
  margin-top: auto;   /* pousse le bouton tout en bas */
}

💡 Astuce : margin-top: auto dans un flex = « prends tout l'espace libre au-dessus de moi ». C'est un super truc à retenir.

🛠️ Exercices pas à pas

Exercice 1 · Ma navbarfacile

  1. Crée seance15/index.html avec un <nav> : un logo (texte ou emoji) + une <ul> de 4 liens.
  2. Mets le <nav> en flex avec justify-content: space-between et align-items: center.
  3. Mets la <ul> en flex avec gap: 20px et enlève les puces (list-style: none).
  4. Ajoute un effet :hover sur les liens (changement de couleur).

Exercice 2 · La rangée de cartesmoyen

  1. Sous la navbar, crée une <section class="cartes"> avec 3 cartes : image, titre, paragraphe et bouton.
  2. Mets la section en display: flex; flex-wrap: wrap; gap: 20px; et chaque carte en flex: 1 1 250px;.
  3. Écris un texte plus long dans une des cartes : les 3 cartes gardent-elles la même hauteur ?
  4. Colle les boutons en bas des cartes avec flex-direction: column + margin-top: auto.

Exercice 3 · La bannière de bienvenuemoyen

  1. Entre la navbar et les cartes, ajoute une bannière avec un texte à gauche et une image à droite.
  2. Mets la bannière en flex avec align-items: center et gap: 30px.
  3. Donne flex: 1 au texte et à l'image pour qu'ils prennent chacun la moitié.

🏆 Défi bonus : Le footer en 3 colonnes

Ajoute un <footer> en flex avec 3 colonnes : « À propos », « Liens utiles » (une liste) et « Suivez-nous » (des emojis de réseaux sociaux).

Les colonnes doivent passer l'une sous l'autre sur un petit écran grâce à flex-wrap et flex: 1 1 200px.

⚠️ Erreurs fréquentes

Mes liens de menu sont l'un sous l'autre
La <ul> aussi doit être en display: flex
Il reste des puces et un décalage à gauche dans le menu
list-style: none; margin: 0; padding: 0; sur la <ul>
flex-grow ne fait rien
flex-grow se met sur les enfants, et le parent doit être en flex
Mes cartes sont toutes petites sur mobile
J'utilise flex: 1 1 250px + flex-wrap: wrap sur le parent

📚 Vocabulaire

Navbar
La barre de navigation en haut d'un site.
flex-grow
La capacité d'un élément à grandir pour prendre l'espace libre.
flex-basis
La taille de départ d'un élément flex.
flex
Le raccourci de flex-grow, flex-shrink et flex-basis.
Carte (card)
Un bloc qui présente un élément : image, titre, texte, bouton.
