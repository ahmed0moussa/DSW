📒 La note : ce qu'il faut comprendre

1Les pseudo-classes

Une pseudo-classe vise un élément dans un état ou une position particulière. Elle commence par :.

  • :hover : la souris est dessus.
  • :focus : le champ est sélectionné (on écrit dedans).
  • :active : on est en train de cliquer.
  • :first-child / :last-child : le premier / le dernier enfant.
  • :nth-child(2) : le 2e enfant. :nth-child(even) : les pairs, :nth-child(odd) : les impairs.
HTML
<ul>
  <li>1. Premier (first-child)</li>
  <li>2. Pair</li>
  <li>3. Impair</li>
  <li>4. Pair</li>
</ul>
<input placeholder="Clique ici (focus)">
CSS
li:nth-child(even) { background: #e3f3f3; }
li:first-child { font-weight: bold; color: #e67e22; }
input:focus { outline: 3px solid #288b8b; }
li { padding: 4px; list-style: none; }
Résultat

💡 Astuce : :nth-child(even) est parfait pour colorer une ligne sur deux dans un tableau.

2transition : un changement en douceur

Sans transition, le changement au :hover est immédiat. Avec transition, il dure un certain temps.

transition: propriété durée; → ex. transition: background-color 0.3s; ou transition: all 0.3s;.

On écrit la transition sur l'élément normal, pas dans le :hover.

HTML
<button class="bouton">Survole-moi</button>
CSS
.bouton {
  background: #288b8b; color: white; padding: 12px 24px;
  border: none; border-radius: 8px; font-size: 16px;
  transition: background-color 0.4s, border-radius 0.4s;
}
.bouton:hover {
  background: #e67e22;
  border-radius: 30px;
}
Résultat

3transform : bouger sans casser la page

  • translate(x, y) : déplacer (ex. translateY(-8px) monte de 8px).
  • scale(1.2) : agrandir de 20 %. scale(0.8) : rétrécir.
  • rotate(10deg) : tourner de 10 degrés.
  • On peut combiner : transform: scale(1.1) rotate(-3deg);.
HTML
<div class="c monte">monte</div>
<div class="c zoom">zoom</div>
<div class="c tourne">tourne</div>
CSS
.c { display: inline-block; width: 90px; padding: 20px 0; margin: 8px; text-align: center;
     background: #e3f3f3; border-radius: 10px; transition: transform 0.3s; }
.monte:hover { transform: translateY(-10px); }
.zoom:hover { transform: scale(1.2); }
.tourne:hover { transform: rotate(15deg); }
Résultat

💡 Astuce : Passe la souris sur chaque boîte du résultat ! transform + transition = le duo le plus utilisé des sites modernes.

4Un menu déroulant en CSS

Le sous-menu est caché (display: none). Quand on survole le parent, il apparaît (display: block).

Le sélecteur .menu:hover .sous-menu veut dire : « le .sous-menu qui est dans un .menu survolé ».

HTML
<div class="menu">
  <span>Jeux ▾</span>
  <div class="sous-menu">
    <a href="#">Aventure</a>
    <a href="#">Sport</a>
    <a href="#">Réflexion</a>
  </div>
</div>
CSS
.menu { position: relative; display: inline-block; }
.sous-menu { display: none; position: absolute; background: white;
             box-shadow: 0 4px 10px rgba(0,0,0,0.2); min-width: 140px; }
.menu:hover .sous-menu { display: block; }
.sous-menu a { display: block; padding: 8px; color: #22303c; text-decoration: none; }
.sous-menu a:hover { background: #e3f3f3; }
.menu > span { background: #22303c; color: white; padding: 8px 14px; display: inline-block; }
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Mes boutonsfacile

  1. Crée seance15/index.html avec 4 boutons (4 classes différentes).
  2. Pour chacun, crée un effet :hover différent : couleur, bordure, ombre, coins arrondis.
  3. Ajoute une transition de 0.3s sur chaque bouton. Compare avec et sans.
  4. Ajoute un effet :active (le bouton rétrécit avec transform: scale(0.95)).

Exercice 2 · Les cartes qui bougentmoyen

  1. Crée 3 cartes avec une image. Au :hover, la carte monte (translateY(-10px)) et l'ombre grandit.
  2. Au :hover de la carte, l'image zoome (.carte:hover img { transform: scale(1.1); }). Ajoute overflow: hidden sur la carte pour que l'image ne déborde pas.
  3. Crée un tableau de scores et colore une ligne sur deux avec tr:nth-child(even).

Exercice 3 · Le menu déroulantdifficile

  1. Crée une navbar avec 4 liens. Le 2e lien « Jeux ▾ » a un sous-menu de 3 liens.
  2. Cache le sous-menu avec display: none et position: absolute.
  3. Affiche-le au survol avec .menu:hover .sous-menu { display: block; }.
  4. Ajoute un style :focus visible sur les liens (pour les personnes qui naviguent au clavier avec Tab).

🏆 Défi bonus : La carte qui se retourne

Crée une carte de jeu qui se retourne au survol pour montrer son dos (transform: rotateY(180deg)). Cherche « flip card » sur W3Schools How To.

Bonus : un formulaire de connexion dont les champs s'agrandissent légèrement et changent de bordure au :focus.

⚠️ Erreurs fréquentes

Ma transition ne marche qu'à l'aller
La transition va sur l'élément normal, pas dans :hover
transition: 0.3s sans effet
La propriété qui change doit avoir une valeur de départ (ex. une couleur de fond au départ)
J'écris deux transform : seul le dernier marche
Je les combine sur une ligne : transform: scale(1.1) rotate(5deg);
Mon sous-menu disparaît quand je descends la souris
Le sous-menu doit être dans l'élément .menu survolé

📚 Vocabulaire

Pseudo-classe
Un état ou une position d'un élément (:hover, :nth-child).
Transition
Le passage progressif d'un style à un autre.
Transformation
Déplacer, agrandir, tourner un élément (transform).
Focus
Quand un élément est sélectionné (au clic ou avec la touche Tab).
Dropdown
Un menu déroulant.
