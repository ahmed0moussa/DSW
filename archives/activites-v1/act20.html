Mini Project : FAQ Accordion

utilisez W3Schools

Objectif : creer une page FAQ interactive avec HTML et CSS seulement, sans JavaScript.

Centre d'aide

Cette page aide les visiteurs a trouver des reponses rapidement. Cliquez sur une question pour afficher la reponse.

Commencez avec une structure HTML : header, main, sections et footer. Ensuite ajoutez le style avec CSS.
CSS permet de changer les couleurs, les tailles, les espacements, les images, les animations et le responsive.
Utilisez width en pourcentage, max-width, grid ou flexbox, puis ajoutez @media pour les petits ecrans.
On cache un input checkbox, puis on utilise input:checked en CSS pour afficher ou cacher un contenu.

1. Structure

Creer une intro-card et plusieurs accordion-item avec input, label et content.

2. Style

Ajouter grid, colors, borders, padding, border-radius et transitions.

3. Bonus

Changer les questions, ajouter une image et adapter la page pour mobile.
