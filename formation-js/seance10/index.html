Séance 10 · Les formulaires : lire ce que tape le visiteur

Les formulaires HTML que tu connais vont enfin servir à quelque chose ! JavaScript peut lire ce que le visiteur écrit, vérifier que c'est correct et lui répondre directement sur la page.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant → Intermédiaire
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Lire la valeur d'un champ avec .value.
  • Réagir à l'envoi d'un formulaire avec l'événement submit et preventDefault().
  • Vérifier les réponses et afficher un message d'erreur ou de succès sur la page.

🔁 Rappel

addEventListener("click", function () { … }) lance une fonction au clic. textContent change un texte, classList change le style. Le formulaire HTML : <form>, <label>, <input>, <button>.

📒 La note : ce qu'il faut comprendre

1Lire un champ : .value

La propriété .value d'un <input> contient ce que le visiteur a tapé (toujours sous forme de texte).

HTML
<input id="prenom" placeholder="Ton prénom">
<button id="ok">OK</button>
<p id="reponse"></p>
JavaScript
document.querySelector("#ok").addEventListener("click", function () {
  const prenom = document.querySelector("#prenom").value;
  document.querySelector("#reponse").textContent = "Salut " + prenom + " ! 👋";
});
Résultat

2L'événement submit et preventDefault

Quand on envoie un formulaire, le navigateur recharge la page par défaut. e.preventDefault() l'en empêche : c'est JavaScript qui s'occupe de tout.

Avantage de submit : ça marche avec le bouton et avec la touche Entrée.

HTML
<form id="formulaire">
  <input id="ville" placeholder="Ta ville">
  <button>Envoyer</button>
</form>
<p id="msg"></p>
JavaScript
document.querySelector("#formulaire").addEventListener("submit", function (e) {
  e.preventDefault();
  const ville = document.querySelector("#ville").value;
  document.querySelector("#msg").textContent = "Tu habites à " + ville;
});
Résultat

3Vérifier les réponses

On vérifie avec des conditions. .trim() enlève les espaces au début et à la fin. .length donne le nombre de caractères.

HTML
<form id="f">
  <input id="pseudo" placeholder="Pseudo (3 lettres min.)">
  <button>Valider</button>
</form>
<p id="info"></p>
CSS
.erreur { color: #c0392b; } .succes { color: #2e8b57; }
JavaScript
document.querySelector("#f").addEventListener("submit", function (e) {
  e.preventDefault();
  const pseudo = document.querySelector("#pseudo").value.trim();
  const info = document.querySelector("#info");
  if (pseudo.length < 3) {
    info.textContent = "❌ Ton pseudo doit avoir au moins 3 lettres.";
    info.className = "erreur";
  } else {
    info.textContent = "✅ Bienvenue " + pseudo + " !";
    info.className = "succes";
  }
});
Résultat

4Les nombres, les cases à cocher et les listes

  • Un nombre : Number(champ.value) (comme pour prompt).
  • Une case à cocher : case.checked vaut true ou false.
  • Une liste <select> : .value donne la valeur de l'option choisie.
  • L'événement "input" se déclenche à chaque lettre tapée : parfait pour un aperçu en direct.
HTML
<input id="texte" placeholder="Écris ici…">
<p>Aperçu : <strong id="apercu"></strong> (<span id="nb">0</span> caractères)</p>
JavaScript
const champ = document.querySelector("#texte");
champ.addEventListener("input", function () {
  document.querySelector("#apercu").textContent = champ.value;
  document.querySelector("#nb").textContent = champ.value.length;
});
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Le message personnaliséfacile

  1. Crée un formulaire avec un champ « Prénom » et un champ « Plat préféré ».
  2. À l'envoi (submit + preventDefault), affiche sous le formulaire : « Salut Nour, toi aussi tu aimes le couscous ? 😋 ».
  3. Vérifie que ça marche aussi avec la touche Entrée.

Exercice 2 · L'inscription vérifiéemoyen

  1. Formulaire : pseudo, âge, email, case « J'accepte le règlement ».
  2. Vérifie : pseudo d'au moins 3 lettres, âge entre 10 et 18, email qui contient @ (email.includes("@")), case cochée.
  3. Affiche la première erreur trouvée en rouge, ou un message de succès en vert.
  4. Bonus : la bordure du champ en erreur devient rouge (une classe CSS).

Exercice 3 · L'aperçu en directmoyen

  1. Crée un <textarea> « Ton message » limité à 100 caractères.
  2. Avec l'événement input, affiche « 37 / 100 » en dessous pendant que le visiteur écrit.
  3. Quand on dépasse 90 caractères, le compteur devient orange ; à 100, rouge.

🏆 Défi bonus : Le calculateur de moyenne

Crée 4 champs de notes et 4 champs de coefficients. Au clic, calcule la moyenne pondérée (comme dans le bulletin de la formation HTML !), affiche-la avec 2 chiffres après la virgule (moyenne.toFixed(2)) et la mention.

⚠️ Erreurs fréquentes

La page se recharge et mon message disparaît
J'ajoute e.preventDefault(); au début de la fonction submit
value est vide alors que j'ai écrit dans le champ
Je lis .value dans la fonction (au moment du clic), pas avant
"12" + "5" donne "125"
Number(champ.value) avant de calculer
J'écoute submit sur le bouton
submit s'écoute sur le <form>

📚 Vocabulaire

value
Le contenu d'un champ de formulaire.
submit
L'événement d'envoi d'un formulaire.
preventDefault()
Empêche le comportement normal du navigateur (ici, recharger la page).
trim()
Enlève les espaces au début et à la fin d'un texte.
checked
true si une case est cochée.
Validation
Vérifier que les réponses sont correctes.
