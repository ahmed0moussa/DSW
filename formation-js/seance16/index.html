Séance 16 · Mini-projet : le quiz

Fin du module 3 ! Tu crées un quiz interactif : les questions sont rangées dans un tableau d'objets, le joueur clique sur une réponse, la page lui dit si c'est juste, compte les points et affiche le score final.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire · Mini-projet
  • 🧰 Outils : VS Code, Live Server, F12

🎯 Objectif : à la fin de la séance, je saurai…

  • Organiser les données d'une application dans un tableau d'objets.
  • Afficher une question à la fois et passer à la suivante.
  • Gérer un score et un écran de fin avec un bouton « Rejouer ».

🔁 Rappel

Module 3 : les tableaux ([ ], indice, length), les objets ({ }, objet.propriete), setTimeout, localStorage.

📒 La note : ce qu'il faut comprendre

1Les données du quiz

Chaque question est un objet : le texte, les choix possibles (un tableau) et l'indice de la bonne réponse.

JavaScript
const questions = [
  {
    question: "Quelle balise crée un lien ?",
    choix: ["<p>", "<a>", "<img>"],
    bonne: 1
  },
  {
    question: "Quelle propriété CSS change la couleur du texte ?",
    choix: ["color", "background", "font-size"],
    bonne: 0
  }
];

2L'état du jeu

Deux variables suffisent pour savoir où on en est :

JavaScript
let numero = 0;   // la question affichée (indice dans le tableau)
let score = 0;    // les bonnes réponses

💡 Astuce : On appelle ça l'état de l'application. Toute la page est construite à partir de ces variables.

3Afficher une question

HTML
<h3 id="q"></h3>
<div id="choix"></div>
<p id="res"></p>
JavaScript
const questions = [
  { question: "2 + 2 = ?", choix: ["3", "4", "5"], bonne: 1 },
  { question: "Capitale de la Tunisie ?", choix: ["Sfax", "Tunis", "Sousse"], bonne: 1 }
];
let numero = 0, score = 0;

function afficherQuestion() {
  const q = questions[numero];
  document.querySelector("#q").textContent = q.question;
  const zone = document.querySelector("#choix");
  zone.innerHTML = "";
  q.choix.forEach(function (texte, i) {
    const b = document.createElement("button");
    b.textContent = texte;
    b.addEventListener("click", function () { repondre(i); });
    zone.append(b);
  });
}

function repondre(i) {
  if (i === questions[numero].bonne) score++;
  numero++;
  if (numero < questions.length) {
    afficherQuestion();
  } else {
    document.querySelector("#q").textContent = "Terminé !";
    document.querySelector("#choix").innerHTML = "";
    document.querySelector("#res").textContent = "Score : " + score + " / " + questions.length;
  }
}

afficherQuestion();
Résultat

💡 Astuce : forEach(function (texte, i) { … }) parcourt le tableau en donnant l'élément et son indice.

4Montrer si c'est juste

Pour que le joueur voie la correction : on colore le bouton cliqué en vert ou en rouge, on bloque les autres boutons (disabled = true), et on passe à la question suivante après 1 seconde avec setTimeout.

JavaScript
bouton.classList.add(i === q.bonne ? "juste" : "faux");

🛠️ Exercices pas à pas

Exercice 1 · Les questionsmoyen

  1. Choisis un thème et écris au moins 6 questions dans un tableau d'objets { question, choix, bonne }.
  2. Crée les variables d'état numero et score.
  3. Vérifie dans la console : console.log(questions[0].choix[questions[0].bonne]) affiche la bonne réponse.

Exercice 2 · Le jeudifficile

  1. Écris afficherQuestion() : le texte de la question et un bouton par choix.
  2. Écris repondre(i) : ajoute 1 au score si c'est juste, colore le bouton, bloque les boutons, puis question suivante après 1 seconde.
  3. Affiche la progression : « Question 3 / 6 ».

Exercice 3 · L'écran de finmoyen

  1. À la fin, affiche le score et un message selon le résultat (bravo, pas mal, à revoir).
  2. Ajoute un bouton « Rejouer » qui remet numero et score à 0 et relance afficherQuestion().
  3. Sauvegarde le meilleur score dans localStorage et affiche-le.

🏆 Défi bonus : Le quiz chronométré

Ajoute un compte à rebours de 10 secondes par question (setInterval). Si le temps est écoulé, la réponse est comptée fausse et on passe à la suivante. Bonus : mélange l'ordre des questions au début de chaque partie.

⚠️ Erreurs fréquentes

Erreur « Cannot read properties of undefined (reading 'question') »
numero a dépassé la dernière question : je teste numero < questions.length avant d'afficher
On peut cliquer 3 fois sur la même question et gagner 3 points
Je bloque les boutons après le premier clic (disabled = true)
Le bouton « Rejouer » garde l'ancien score
Je remets toutes les variables d'état à 0
La bonne réponse est toujours fausse
bonne est un indice : il commence à 0

📚 Vocabulaire

disabled
Un bouton désactivé, qu'on ne peut plus cliquer.
Ternaire
