Séance 09 · Les événements : réagir aux clics

C'est LA séance magique : ta page va réagir quand on clique ! Un bouton like qui compte, un mode sombre, une image qui change… Tout ça grâce aux événements.

🎯 Objectif : à la fin de la séance, je saurai…

  • Exécuter une fonction quand on clique avec addEventListener("click", …).
  • Créer un compteur qui se met à jour à chaque clic.
  • Utiliser d'autres événements : mouseover, mouseout, keydown.

🔁 Rappel

classList.toggle("nom") ajoute ou enlève une classe. Les fonctions : function nom() { … }. Une variable let peut changer de valeur.

📒 La note : ce qu'il faut comprendre

1Écouter un clic

Un événement, c'est quelque chose qui arrive sur la page : un clic, une touche, la souris qui passe…

element.addEventListener("click", maFonction) veut dire : « quand on clique sur l'élément, lance maFonction ».

HTML
<button id="bouton">Clique-moi</button>
<p id="texte">…</p>
JavaScript
const bouton = document.querySelector("#bouton");
const texte = document.querySelector("#texte");

function quandOnClique() {
  texte.textContent = "Bravo, tu as cliqué ! 🎉";
}

bouton.addEventListener("click", quandOnClique);
Résultat

💡 Astuce : On écrit quandOnClique sans parenthèses : on donne la fonction au navigateur, c'est lui qui l'appellera au moment du clic.

2Le compteur de likes

Une variable garde le nombre de clics. À chaque clic, on ajoute 1 et on met à jour l'affichage.

HTML
<button id="like">❤️ J'aime</button>
<span id="total">0</span>
JavaScript
let likes = 0;
const total = document.querySelector("#total");

document.querySelector("#like").addEventListener("click", function () {
  likes++;
  total.textContent = likes;
});
Résultat

💡 Astuce : Ici la fonction est écrite directement dans addEventListener (une fonction sans nom, dite anonyme). C'est très courant.

3Le mode sombre en 3 lignes

HTML
<button id="theme">🌙 Mode sombre</button>
<p>Clique sur le bouton plusieurs fois.</p>
CSS
body.sombre { background: #1f2933; color: white; }
JavaScript
document.querySelector("#theme").addEventListener("click", function () {
  document.body.classList.toggle("sombre");
});
Résultat

4D'autres événements

  • "click" : un clic.
  • "mouseover" / "mouseout" : la souris arrive sur l'élément / le quitte.
  • "keydown" : une touche du clavier est enfoncée (on l'écoute souvent sur document).
  • "input" : le texte d'un champ change (séance 10).
HTML
<div id="zone" style="padding:20px;background:#e3f3f3;border-radius:8px">Passe la souris ici</div>
JavaScript
const zone = document.querySelector("#zone");
zone.addEventListener("mouseover", function () {
  zone.textContent = "Coucou ! 👋";
});
zone.addEventListener("mouseout", function () {
  zone.textContent = "Reviens !";
});
Résultat

5Savoir quelle touche : l'objet event

La fonction reçoit automatiquement un paramètre event (souvent écrit e) avec des informations sur l'événement.

HTML
<p>Clique dans ce cadre puis appuie sur une touche :</p>
<p id="touche" style="font-size:24px">…</p>
JavaScript
document.addEventListener("keydown", function (e) {
  document.querySelector("#touche").textContent = "Touche : " + e.key;
});
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Le compteurfacile

  1. Crée une page avec un nombre affiché (<span id="compteur">0</span>) et 3 boutons : « + 1 », « − 1 », « Remise à zéro ».
  2. Crée let valeur = 0; et une fonction afficher() qui écrit valeur dans le span.
  3. Pour chaque bouton, addEventListener("click", …) change valeur puis appelle afficher().
  4. Bonus : le nombre devient rouge quand il est négatif (classe + condition).

Exercice 2 · Le mode sombrefacile

  1. Dans le CSS, crée body.sombre { … } avec un fond foncé et un texte clair.
  2. Ajoute un bouton 🌙 qui fait document.body.classList.toggle("sombre").
  3. Bonus : le texte du bouton change entre « 🌙 Mode sombre » et « ☀️ Mode clair » (indice : classList.contains).

Exercice 3 · La carte qui réagitmoyen

  1. Crée une carte avec une image et un texte caché (classe .cache).
  2. Au clic sur un bouton « Voir plus », le texte apparaît, et le bouton devient « Voir moins ».
  3. Au mouseover sur l'image, elle grandit (une classe CSS avec transform: scale(1.1)), au mouseout elle revient.

🏆 Défi bonus : La galerie précédent / suivant

Crée une image et deux boutons « ◀ » et « ▶ ». Range 4 adresses d'images dans des variables (ou dans un tableau si tu veux prendre de l'avance sur la séance 13). Chaque clic affiche l'image suivante ou précédente.

Bonus : les touches flèche gauche et flèche droite du clavier marchent aussi (e.key === "ArrowRight").

⚠️ Erreurs fréquentes

addEventListener("click", maFonction()) : la fonction se lance tout de suite
Sans parenthèses : addEventListener("click", maFonction)
addEventListener("onclick", …)
Le nom de l'événement est "click" (sans « on »)
Mon compteur revient toujours à 1
La variable let likes = 0; doit être créée en dehors de la fonction
Erreur « Cannot read properties of null (reading 'addEventListener') »
Le bouton n'a pas été trouvé : je vérifie l'id et le sélecteur #

📚 Vocabulaire

Événement
Une action qui arrive sur la page : clic, touche, souris…
addEventListener
Demande au navigateur de lancer une fonction quand un événement arrive.
Écouteur (listener)
La fonction qui attend l'événement.
Fonction anonyme
Une fonction sans nom, écrite directement dans addEventListener.
event (e)
L'objet qui contient les infos de l'événement (ex. e.key).
