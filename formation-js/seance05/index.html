Séance 05 · Les boucles : répéter

🎯 Objectif : à la fin de la séance, je saurai…

  • Répéter une action un nombre précis de fois avec une boucle for.
  • Répéter tant qu'une condition est vraie avec une boucle while.
  • Utiliser le compteur de la boucle dans un calcul ou un texte.

🔁 Rappel

Les conditions : if (note >= 10) { … } else { … }. Les comparaisons ===, <, >. Les opérateurs && (ET) et || (OU).

📒 La note : ce qu'il faut comprendre

1La boucle for

La boucle for a 3 parties, séparées par des ; :

  • Le départ : let i = 1 → on crée un compteur i.
  • La condition : i <= 5 → on continue tant que c'est vrai.
  • Le pas : i++ → après chaque tour, on ajoute 1 à i (i++ veut dire i = i + 1).
JavaScript
for (let i = 1; i <= 5; i++) {
  console.log("Tour numéro " + i);
}
Résultat

2Utiliser le compteur

Le compteur i change à chaque tour : on peut l'utiliser pour calculer.

JavaScript
// La table de 7
for (let i = 1; i <= 10; i++) {
  console.log(`7 x ${i} = ${7 * i}`);
}
Résultat

3Compter à l'envers ou de 2 en 2

JavaScript
// Compte à rebours
for (let i = 5; i >= 1; i--) {
  console.log(i + "…");
}
console.log("Décollage ! 🚀");

// Les nombres pairs
for (let i = 0; i <= 10; i += 2) {
  console.log(i);
}

💡 Astuce : i-- enlève 1 à chaque tour. i += 2 ajoute 2 à chaque tour.

4La boucle while

while (« tant que ») répète tant que la condition est vraie. On l'utilise quand on ne sait pas à l'avance combien de tours il faudra.

JavaScript
let argent = 20;
let jours = 0;

while (argent > 0) {
  argent = argent - 3;   // je dépense 3 DT par jour
  jours++;
}
console.log("Mon argent a duré " + jours + " jours.");
Résultat

💡 Astuce : Attention à la boucle infinie : si la condition reste toujours vraie, la boucle ne s'arrête jamais et la page se bloque. Il faut que quelque chose change à chaque tour !

5Une boucle + une condition

JavaScript
for (let i = 1; i <= 15; i++) {
  if (i % 3 === 0) {
    console.log(i + " 👏");   // multiple de 3
  } else {
    console.log(i);
  }
}

💡 Astuce : i % 3 donne le reste de la division par 3. Si le reste vaut 0, i est un multiple de 3.

🛠️ Exercices pas à pas

Exercice 1 · Compterfacile

  1. Affiche les nombres de 1 à 20 avec une boucle for.
  2. Affiche les nombres de 10 à 0 (compte à rebours), puis « Bonne année ! 🎆 ».
  3. Affiche les nombres impairs de 1 à 19.

Exercice 2 · Ma table de multiplicationfacile

  1. Crée const nombre = 8;.
  2. Avec une boucle, affiche la table de nombre de 1 à 10 : « 8 x 1 = 8 », etc.
  3. Change nombre pour afficher une autre table.

Exercice 3 · La tireliremoyen

  1. Tu as 0 DT et tu ajoutes 5 DT chaque semaine. Avec while, calcule le nombre de semaines pour avoir au moins 120 DT (le prix d'un jeu).
  2. Affiche chaque semaine : « Semaine 3 : 15 DT ».
  3. Bonus : chaque semaine, tu ajoutes 1 DT de plus que la semaine d'avant (5, 6, 7…).

🏆 Défi bonus : Fizz Buzz

Affiche les nombres de 1 à 30, mais : les multiples de 3 sont remplacés par « Fizz », les multiples de 5 par « Buzz », et les multiples de 3 ET de 5 par « FizzBuzz ».

Ce petit jeu est très connu : on le demande parfois aux développeurs en entretien d'embauche !

⚠️ Erreurs fréquentes

La page se bloque : boucle infinie
Quelque chose doit changer dans la boucle pour que la condition devienne fausse (i++, argent -= 3)
J'écris des virgules : for (let i = 0, i < 5, i++)
Ce sont des points-virgules : for (let i = 0; i < 5; i++)
Ma boucle fait un tour de trop ou de moins
Je vérifie < ou <= et la valeur de départ
J'oublie let dans le départ
for (let i = 1; …)

📚 Vocabulaire

Boucle
Un code qui se répète.
Itération
Un tour de boucle.
Compteur
La variable (souvent i) qui compte les tours.
i++ / i--
Ajouter 1 / enlever 1.
Boucle infinie
Une boucle qui ne s'arrête jamais : un bug !
% (modulo)
Le reste d'une division : 10 % 3 vaut 1.
