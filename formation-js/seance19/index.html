1Le diaporama

Un tableau d'images, un numéro, une fonction afficher(n). Les boutons changent le numéro, setInterval le fait tout seul.

JavaScript
const images = ["img/1.jpg", "img/2.jpg", "img/3.jpg"];
let numero = 0;
const photo = document.querySelector("#photo");

function afficher(n) {
  numero = (n + images.length) % images.length;   // reste entre 0 et 2
  photo.src = images[numero];
}

document.querySelector("#suivant").addEventListener("click", () => afficher(numero + 1));
document.querySelector("#precedent").addEventListener("click", () => afficher(numero - 1));
setInterval(() => afficher(numero + 1), 4000);

💡 Astuce : (n + images.length) % images.length : une formule magique pour revenir au début après la dernière image, et à la fin avant la première.

2L'accordéon (FAQ)

HTML
<button class="question">Combien ça coûte ?</button>
<div class="reponse">L'inscription est gratuite !</div>
<button class="question">Quand ont lieu les activités ?</button>
<div class="reponse">Le mercredi et le samedi.</div>
CSS
.reponse { display: none; padding: 6px 10px; background: #f4f6f9; }
.question.ouverte + .reponse { display: block; }
.question { width: 100%; text-align: left; margin-top: 4px; }
JavaScript
for (const question of document.querySelectorAll(".question")) {
  question.addEventListener("click", function () {
    question.classList.toggle("ouverte");
  });
}
Résultat

💡 Astuce : Le sélecteur CSS + vise l'élément juste après : .question.ouverte + .reponse.

3La galerie filtrée

Exactement la boutique de la séance 14, adaptée à ton site : un tableau d'objets, une fonction afficher(liste), des boutons qui appellent afficher(photos.filter(…)).

JavaScript
const photos = [
  { titre: "Plage", categorie: "mer", image: "images/plage.jpg" },
  { titre: "Forêt", categorie: "nature", image: "images/foret.jpg" }
];

function afficher(liste) {
  galerie.innerHTML = "";
  for (const p of liste) {
    const figure = document.createElement("figure");
    figure.innerHTML = `<img src="${p.image}" alt="${p.titre}">
                        <figcaption>${p.titre}</figcaption>`;
    galerie.append(figure);
  }
}

🛠️ Exercices pas à pas

Exercice 1 · Le diaporamamoyen

  1. Un tableau de 3 à 5 images de ton site, une <img id="photo">, deux boutons ◀ ▶.
  2. La fonction afficher(n) avec la formule modulo.
  3. Le défilement automatique toutes les 4 secondes avec setInterval.
  4. Bonus : des petits points ● ● ● sous l'image, le point actif est coloré.

Exercice 2 · La FAQ ou la galeriedifficile

  1. FAQ : 4 questions/réponses, toggle("ouverte"), une flèche qui tourne (CSS transform: rotate).
  2. ou Galerie : un tableau d'au moins 6 objets, afficher(liste), 3 boutons de filtre + « Tout voir ».
  3. Le bouton du filtre actif est mis en valeur (classe .actif).

Exercice 3 · La session de testsfacile

  1. Ouvre la console sur chaque page : corrige toutes les erreurs rouges.
  2. Teste chaque interaction en mode téléphone.
  3. Échange ton ordinateur avec ton voisin : il note sur un papier tout ce qui ne marche pas ou n'est pas clair. Corrige.

🏆 Défi bonus : La fenêtre (modale)

Dans ta galerie, un clic sur une photo l'ouvre en grand par-dessus la page, avec un fond noir transparent et un bouton ✖ (cherche « modal image » sur W3Schools How To). La touche Échap la ferme aussi.

⚠️ Erreurs fréquentes

Le diaporama affiche une image cassée après la dernière
J'utilise la formule (n + longueur) % longueur
Toutes les réponses de la FAQ s'ouvrent ensemble
Je fais toggle sur la question cliquée, dans la boucle
Mes filtres ne trouvent rien
Les catégories du tableau et des boutons doivent être écrites exactement pareil
Ça marche sur mon ordinateur mais pas chez mon voisin
Je vérifie les chemins des images (majuscules, dossiers)
