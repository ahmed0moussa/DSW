Séance 02 · Mon premier JavaScript

Aujourd'hui tu écris tes premières lignes de JavaScript ! Tu découvres où on écrit le code, comment l'ordinateur te répond dans la console, et comment lire un message d'erreur.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, Chrome (console F12)
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Ajouter du JavaScript à une page avec la balise <script> et un fichier .js.
  • Afficher des messages avec console.log() et les lire dans la console (F12).
  • Lire un message d'erreur et retrouver la ligne qui pose problème.

🔁 Rappel

Un algorithme est une suite d'étapes précises. Les 3 briques sont la séquence, la condition et la boucle. Un programme, c'est un algorithme écrit dans un langage comme JavaScript.

📒 La note : ce qu'il faut comprendre

1HTML, CSS… et JavaScript

  • HTML = la structure (les murs).
  • CSS = la décoration (la peinture).
  • JavaScript = l'action (l'électricité) : il réagit aux clics, calcule, change la page, crée des jeux.

💡 Astuce : JavaScript n'a rien à voir avec le langage Java : c'est juste un nom qui se ressemble !

2Où écrire le JavaScript ?

Comme le CSS, le JavaScript peut être dans la page ou dans un fichier séparé. La meilleure façon : un fichier script.js relié juste avant </body>.

Pourquoi à la fin ? Parce que le navigateur lit la page de haut en bas : à la fin, tous les éléments HTML existent déjà.

HTML
<body>
  <h1>Ma page</h1>

  <script src="script.js"></script>
</body>

3console.log : l'ordinateur te répond

console.log() affiche un message dans la console. Ouvre-la avec F12 → onglet Console.

Le texte s'écrit entre guillemets. Chaque instruction se termine par un point-virgule ;.

JavaScript
console.log("Bonjour !");
console.log("Je m'appelle Sami");
console.log(5 + 3);
Résultat

💡 Astuce : Le visiteur ne voit pas la console : c'est l'outil du développeur pour vérifier son code.

4Les commentaires

Les commentaires sont des notes pour toi. JavaScript les ignore.

JavaScript
// Commentaire sur une ligne

/* Commentaire
   sur plusieurs lignes */

console.log("Ceci s'affiche");

💡 Astuce : Dans VS Code, Ctrl + / met une ligne en commentaire, comme en HTML et en CSS.

5Lire une erreur

Si tu fais une faute, la console affiche une ligne rouge. Elle te dit quoi (le type d'erreur) et où (le fichier et le numéro de ligne, à droite).

JavaScript
console.log("Bonjour");
consol.log("Oups");   // faute de frappe !
Résultat

💡 Astuce : consol is not defined veut dire : « je ne connais pas le mot consol ». Clique sur le nom du fichier à droite de l'erreur : la console t'emmène à la bonne ligne.

🛠️ Exercices pas à pas

Exercice 1 · Mon premier messagefacile

  1. Crée seance02/index.html (squelette avec ! + Entrée) et seance02/script.js.
  2. Relie le script juste avant </body> : <script src="script.js"></script>.
  3. Dans script.js, écris console.log("Bonjour, je m'appelle …");.
  4. Ouvre la page avec Live Server, puis F12 → Console : ton message est là ! 🎉

Exercice 2 · La console calculatricefacile

  1. Affiche le résultat de 5 calculs avec console.log() : 12 + 8, 100 - 37, 6 * 7, 81 / 9, 2 + 3 * 4.
  2. Pourquoi 2 + 3 * 4 donne 14 et pas 20 ? (Comme en maths : la multiplication d'abord.)
  3. Essaie console.log("5" + 3);. Que se passe-t-il ? On en reparlera à la séance 3 !

Exercice 3 · Chasse aux bugsmoyen

  1. Copie ces 3 lignes dans ton script : console.log("Salut"), console.log("ça va ?"; et Console.log("au revoir");.
  2. Ouvre la console : lis le message d'erreur et trouve la ligne.
  3. Corrige les 2 erreurs une par une (une parenthèse manquante, une majuscule en trop).

🏆 Défi bonus : Le dessin dans la console

Avec plusieurs console.log(), dessine un sapin, une maison ou ton prénom en grand avec des caractères (*, #, /, \).

⚠️ Erreurs fréquentes

J'oublie les guillemets : console.log(Bonjour);
Un texte est toujours entre guillemets : console.log("Bonjour");
J'écris Console.log ou consol.log
JavaScript fait la différence entre majuscules et minuscules : console.log
Je ne vois rien sur la page
console.log écrit dans la console (F12), pas dans la page
Mon script ne marche pas du tout
Je vérifie le chemin dans <script src="…"> et le nom du fichier

📚 Vocabulaire

JavaScript (JS)
Le langage qui rend les pages web interactives.
Script
Un fichier ou un morceau de code JavaScript.
Console
L'outil du navigateur (F12) qui affiche les messages et les erreurs.
Instruction
Une ligne de code qui donne un ordre, terminée par ;.
Erreur (error)
Un message rouge qui dit ce qui ne va pas et où.
Commentaire
Une note ignorée par JavaScript : // ou /* */.
