Séance 17 · Projet 1/4 : choisir mes interactions

Tu as créé ton site en HTML et CSS pendant la première formation. Maintenant, tu vas le rendre vivant avec JavaScript ! Le projet dure 4 séances. Aujourd'hui : on choisit les interactions et on les prépare sur papier.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Projet
  • 🧰 Outils : Ton site du projet HTML/CSS, papier, Excalidraw
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Choisir 3 ou 4 interactions utiles pour mon site.
  • Décrire chaque interaction en français : QUAND… ALORS… (l'algorithme).
  • Préparer le HTML et le CSS nécessaires (ids, classes, état caché / visible).

🔁 Rappel

Tu sais tout faire : variables, conditions, boucles, fonctions, DOM, événements, formulaires, créer des éléments, tableaux, objets, setInterval, localStorage.

📒 La note : ce qu'il faut comprendre

1Le catalogue des interactions

  • ⭐ Menu burger : sur téléphone, le menu est caché derrière ☰ et s'ouvre au clic.
  • ⭐ Mode sombre qui se souvient (localStorage).
  • ⭐ Bouton « retour en haut » qui apparaît quand on descend.
  • ⭐⭐ FAQ en accordéon : la réponse s'ouvre au clic sur la question.
  • ⭐⭐ Formulaire de contact vérifié avec messages d'erreur.
  • ⭐⭐ Diaporama (slider) avec boutons et défilement automatique.
  • ⭐⭐⭐ Galerie ou produits générés depuis un tableau d'objets, avec filtres.
  • ⭐⭐⭐ Quiz sur le thème de ton site.

💡 Astuce : Choisis au moins une ⭐, une ⭐⭐ et, si tu veux un défi, une ⭐⭐⭐. Mieux vaut 3 interactions qui marchent parfaitement que 6 à moitié finies.

2Écrire l'algorithme d'abord

Pour chaque interaction, écris en français : QUAND (l'événement) → ALORS (ce qui change). Exemple pour le menu burger :

Algorithme
QUAND on clique sur le bouton ☰
ALORS le menu reçoit / perd la classe "ouvert"
      (en CSS : .menu        → display: none
                .menu.ouvert → display: flex)
QUAND on clique sur un lien du menu
ALORS le menu perd la classe "ouvert"

3Préparer le HTML et le CSS

  • Des id clairs sur les éléments que JavaScript va chercher : #bouton-menu, #menu, #theme.
  • Des classes d'état en CSS : .ouvert, .cache, .actif, .sombre. JavaScript se contente de les ajouter / enlever.
  • Un fichier js/script.js relié avant </body> sur toutes les pages.
Schéma
mon-site/
├── index.html
├── …
├── css/style.css
├── js/script.js      ← nouveau !
└── images/

🛠️ Exercices pas à pas

Exercice 1 · Je choisisfacile

  1. Ouvre ton site du projet HTML/CSS (fais-en une copie : mon-site-js/).
  2. Choisis 3 ou 4 interactions dans le catalogue, avec au moins une ⭐ et une ⭐⭐.
  3. Pour chacune, note sur quelle page elle sera et pourquoi elle est utile au visiteur.

Exercice 2 · J'écris les algorithmesmoyen

  1. Pour chaque interaction, écris QUAND… ALORS… en français.
  2. Liste les variables dont tu auras besoin (ex. numeroImage, score).
  3. Liste les fonctions (ex. ouvrirMenu(), afficherImage()).

Exercice 3 · Je prépare le terrainmoyen

  1. Ajoute les ids et les éléments HTML nécessaires (bouton ☰, bouton 🌙, zone de la FAQ…).
  2. Écris les classes d'état dans ton CSS (.ouvert, .cache, .sombre…) et teste-les à la main en les ajoutant dans F12.
  3. Crée js/script.js, relie-le sur toutes les pages, et vérifie avec un console.log("script chargé").

🏆 Défi bonus : Prendre de l'avance

Code déjà l'interaction ⭐ la plus simple (par exemple le bouton « retour en haut »).

⚠️ Erreurs fréquentes

Je choisis 8 interactions
3 ou 4 interactions qui marchent valent mieux que 8 à moitié finies
Je commence à coder sans algorithme
QUAND… ALORS… d'abord : on gagne beaucoup de temps
Je mets les styles dans le JavaScript
Les styles vont dans des classes CSS ; JavaScript ajoute / enlève les classes
Mon script ne marche que sur la page d'accueil
Le <script src="js/script.js"> doit être sur toutes les pages

📚 Vocabulaire

Interaction
Quelque chose qui réagit à une action du visiteur.
Classe d'état
Une classe CSS qui représente un état : ouvert, caché, actif…
Menu burger
Le bouton ☰ qui ouvre le menu sur téléphone.
Accordéon
Une liste de blocs qui s'ouvrent et se ferment au clic.
