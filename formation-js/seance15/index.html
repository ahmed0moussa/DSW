Séance 15 · Le temps et la mémoire

Un chronomètre, un diaporama qui défile tout seul, un message qui disparaît après 3 secondes… JavaScript sait gérer le temps. Et avec localStorage, ta page peut se souvenir des choses même après avoir été fermée !

  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, F12 (onglet Application)

🎯 Objectif : à la fin de la séance, je saurai…

  • Lancer une action après un délai avec setTimeout.
  • Répéter une action à intervalle régulier avec setInterval et l'arrêter avec clearInterval.
  • Sauvegarder et relire des données avec localStorage.

🔁 Rappel

Les tableaux [ ] et les objets { }. Une fonction afficher() reconstruit la page à partir des données.

📒 La note : ce qu'il faut comprendre

1setTimeout : plus tard

setTimeout(fonction, délai) lance la fonction une fois, après un délai en millisecondes (1000 ms = 1 seconde).

HTML
<button id="b">Afficher un message</button>
<p id="msg"></p>
JavaScript
document.querySelector("#b").addEventListener("click", function () {
  const msg = document.querySelector("#msg");
  msg.textContent = "✅ Message envoyé !";
  setTimeout(function () {
    msg.textContent = "";      // disparaît après 2 secondes
  }, 2000);
});
Résultat

2setInterval : régulièrement

setInterval(fonction, délai) relance la fonction toutes les X millisecondes, sans s'arrêter.

Pour l'arrêter, on garde son numéro dans une variable et on appelle clearInterval(numero).

HTML
<p style="font-size:32px" id="chrono">0</p>
<button id="start">▶ Démarrer</button>
<button id="stop">⏸ Pause</button>
JavaScript
let secondes = 0;
let minuteur = null;
const chrono = document.querySelector("#chrono");

document.querySelector("#start").addEventListener("click", function () {
  if (minuteur !== null) return;          // déjà lancé
  minuteur = setInterval(function () {
    secondes++;
    chrono.textContent = secondes;
  }, 1000);
});

document.querySelector("#stop").addEventListener("click", function () {
  clearInterval(minuteur);
  minuteur = null;
});
Résultat

3localStorage : la mémoire du navigateur

localStorage garde des données dans le navigateur, même si on ferme la page. Il ne garde que du texte.

  • localStorage.setItem("cle", "valeur") : sauvegarder.
  • localStorage.getItem("cle") : relire (renvoie null s'il n'y a rien).
  • localStorage.removeItem("cle") : effacer.
JavaScript
// Retenir le thème choisi
localStorage.setItem("theme", "sombre");

// Au chargement de la page
const theme = localStorage.getItem("theme");
if (theme === "sombre") {
  document.body.classList.add("sombre");
}

💡 Astuce : Pour voir ce qui est sauvegardé : F12 → onglet Application → Local Storage. Les données restent sur cet ordinateur et ce navigateur seulement.

4Sauvegarder un tableau : JSON

localStorage ne garde que du texte. Pour un tableau ou un objet, on le transforme en texte avec JSON.stringify, et on le retransforme avec JSON.parse.

JavaScript
const taches = ["Réviser", "Ranger"];
localStorage.setItem("taches", JSON.stringify(taches));

const sauvegarde = localStorage.getItem("taches");
const relues = sauvegarde ? JSON.parse(sauvegarde) : [];
console.log(relues);

💡 Astuce : C'est exactement ce qu'il faut pour que ta to-do list de la séance 12 se souvienne des tâches !

⚠️ Erreurs fréquentes

setTimeout(maFonction(), 2000) : ça s'exécute tout de suite
Sans parenthèses : setTimeout(maFonction, 2000)
Mon chrono va de plus en plus vite
J'ai lancé plusieurs setInterval : je vérifie qu'il n'est pas déjà lancé
J'écris le délai en secondes : setInterval(f, 3)
Le délai est en millisecondes : 3 secondes = 3000
localStorage.getItem me renvoie "[object Object]"
J'utilise JSON.stringify pour sauvegarder et JSON.parse pour relire

📚 Vocabulaire

setTimeout
Lance une fonction une fois, après un délai.
setInterval
Relance une fonction régulièrement.
clearInterval
Arrête un setInterval.
Milliseconde (ms)
Un millième de seconde : 1000 ms = 1 s.
localStorage
La mémoire du navigateur, qui reste après la fermeture de la page.
JSON
Une façon d'écrire des tableaux et des objets sous forme de texte.
