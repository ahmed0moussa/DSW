1Le menu burger

En CSS, sur petit écran : le menu est caché, le bouton ☰ est visible, et .menu.ouvert affiche le menu. En JavaScript : un simple toggle.

JavaScript
const boutonMenu = document.querySelector("#bouton-menu");
const menu = document.querySelector(".menu");

boutonMenu.addEventListener("click", function () {
  menu.classList.toggle("ouvert");
});

// Fermer le menu quand on clique sur un lien
for (const lien of menu.querySelectorAll("a")) {
  lien.addEventListener("click", function () {
    menu.classList.remove("ouvert");
  });
}

💡 Astuce : Teste avec F12 → mode téléphone (Ctrl + Shift + M). Sur ordinateur, le bouton ☰ est caché par le CSS.

2Le mode sombre qui se souvient

JavaScript
const boutonTheme = document.querySelector("#theme");

if (localStorage.getItem("theme") === "sombre") {
  document.body.classList.add("sombre");
}

boutonTheme.addEventListener("click", function () {
  document.body.classList.toggle("sombre");
  const theme = document.body.classList.contains("sombre") ? "sombre" : "clair";
  localStorage.setItem("theme", theme);
});

💡 Astuce : Le CSS fait tout le travail : body.sombre { … }, body.sombre .carte { … }. Si tu as des variables CSS (:root), redéfinis-les dans body.sombre !

3Le bouton « retour en haut »

L'événement scroll se déclenche quand on fait défiler la page. window.scrollY donne le nombre de pixels défilés.

window.scrollTo({ top: 0, behavior: "smooth" }) remonte en douceur.

JavaScript
const boutonHaut = document.querySelector("#haut-de-page");

window.addEventListener("scroll", function () {
  if (window.scrollY > 300) {
    boutonHaut.classList.remove("cache");
  } else {
    boutonHaut.classList.add("cache");
  }
});

boutonHaut.addEventListener("click", function () {
  window.scrollTo({ top: 0, behavior: "smooth" });
});

🛠️ Exercices pas à pas

Exercice 1 · Le menu burgermoyen

  1. Ajoute un <button id="bouton-menu">☰</button> dans ton header.
  2. En CSS, dans @media (max-width: 700px) : bouton visible, .menu caché, .menu.ouvert visible en colonne.

Exercice 2 · Le mode sombremoyen

  1. Écris body.sombre { … } et les règles des autres éléments en mode sombre.
  2. Ajoute un bouton 🌙 et le code toggle + localStorage.
  3. Vérifie que le thème reste après F5 et sur toutes les pages du site.

Exercice 3 · Le bouton retour en hautfacile

  1. Ajoute un bouton ⬆ en position: fixed en bas à droite, caché au départ.
  2. Affiche-le quand window.scrollY > 300.
  3. Au clic, remonte en douceur avec scrollTo.

🏆 Défi bonus : La barre de progression

Ajoute une fine barre de couleur en haut de la page qui grandit pendant qu'on lit. Largeur en % = scrollY / (document.body.scrollHeight - window.innerHeight) * 100.

⚠️ Erreurs fréquentes

Le menu ne s'ouvre pas
Je vérifie que le CSS .menu.ouvert existe dans la media query et que la classe est bien ajoutée (F12)
Le thème ne reste pas sur les autres pages
Le code qui lit localStorage doit être dans script.js, relié sur toutes les pages
Erreur « null » sur une page qui n'a pas de bouton ☰
Je vérifie que l'élément existe : if (boutonMenu) { … }
scrollTo ne marche pas
On l'appelle sur window : window.scrollTo(…)
