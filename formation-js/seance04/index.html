Séance 04 · Les conditions : si… sinon…

Un programme doit souvent choisir : SI le joueur a assez de points ALORS il passe au niveau suivant, SINON il recommence. En JavaScript, ce choix s'écrit avec if et else.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, console F12

🎯 Objectif : à la fin de la séance, je saurai…

  • Comparer deux valeurs avec ===, !==, <, >, <=, >=.
  • Écrire une condition avec if, else if et else.
  • Combiner plusieurs conditions avec && (ET) et || (OU).

🔁 Rappel

Une variable garde une valeur : let score = 10;. Les types : nombre, texte, booléen (true / false). On calcule avec + - * /.

📒 La note : ce qu'il faut comprendre

1Comparer : la réponse est vrai ou faux

Une comparaison donne toujours un booléen : true ou false.

  • === : est égal à. !== : est différent de.
  • < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal.
JavaScript
const age = 15;
console.log(age > 12);      // true
console.log(age === 18);    // false
console.log(age !== 18);    // true
Résultat

💡 Astuce : Ne confonds pas : un seul = range une valeur ; trois === comparent.

2if et else

if (condition) { … } : le code entre accolades s'exécute seulement si la condition est vraie.

else { … } : sinon, c'est ce code qui s'exécute.

JavaScript
const note = 13;

if (note >= 10) {
  console.log("Bravo, tu as réussi ! 🎉");
} else {
  console.log("Courage, tu vas y arriver 💪");
}
Résultat

3Plusieurs choix : else if

On teste les conditions dans l'ordre. Dès qu'une est vraie, on s'arrête.

JavaScript
const temperature = 32;

if (temperature >= 30) {
  console.log("Il fait chaud : plage ! 🏖️");
} else if (temperature >= 18) {
  console.log("Il fait bon : balade 🚶");
} else {
  console.log("Il fait froid : chocolat chaud ☕");
}
Résultat

4ET, OU, NON

  • && (ET) : vrai si les deux conditions sont vraies.
  • || (OU) : vrai si au moins une condition est vraie.
  • ! (NON) : inverse : !true donne false.
JavaScript
const age = 14;
const aUnTicket = true;

if (age >= 12 && aUnTicket) {
  console.log("Tu peux entrer au cinéma 🎬");
}

const jour = "samedi";
if (jour === "samedi" || jour === "dimanche") {
  console.log("C'est le week-end !");
}
Résultat

🛠️ Exercices pas à pas

Exercice 1 · Réussi ou pas ?facile

  1. Crée const note = …;.
  2. Si la note est supérieure ou égale à 10, affiche « Admis », sinon « Pas encore ».
  3. Change la note plusieurs fois pour tester les deux cas.

Exercice 2 · La mentionmoyen

  1. Avec else if, affiche la mention : 16 et plus « Très bien », 14 et plus « Bien », 12 et plus « Assez bien », 10 et plus « Passable », sinon « Insuffisant ».
  2. Teste avec 18, 15, 12, 10 et 7.
  3. Pourquoi l'ordre des conditions est-il important ? Essaie de mettre « Passable » en premier.

Exercice 3 · Le portier de la salle de jeuxmoyen

  1. Crée age, aPayé (booléen) et estAccompagne (booléen).
  2. On entre si : on a payé ET (on a 12 ans ou plus OU on est accompagné).
  3. Affiche « Bienvenue ! » ou « Désolé, tu ne peux pas entrer ».

🏆 Défi bonus : Pierre, feuille, ciseaux

Crée deux variables joueur1 et joueur2 qui valent "pierre", "feuille" ou "ciseaux". Écris les conditions qui affichent qui a gagné (ou égalité).

Bonus : l'ordinateur choisit au hasard avec Math.random() (cherche sur W3Schools).

⚠️ Erreurs fréquentes

if (note = 10) avec un seul =
Pour comparer : ===. Un seul = range une valeur
J'oublie les accolades { }
Le code de chaque cas va entre { et }
Je mets un ; après la parenthèse : if (x > 3); {
Pas de ; après if (…)
if (age > 12 && < 18)
Chaque comparaison est complète : age > 12 && age < 18
