Séance 11 · Créer et supprimer des éléments

Jusqu'ici, JavaScript modifiait des éléments qui existaient déjà. Maintenant, il va en créer de nouveaux : ajouter une ligne à une liste, un commentaire, une carte… et les supprimer.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer un nouvel élément avec document.createElement().
  • L'ajouter dans la page avec append() (ou prepend()).
  • Supprimer un élément avec remove().

🔁 Rappel

.value lit un champ, submit + preventDefault() gère l'envoi d'un formulaire, textContent et classList modifient un élément.

📒 La note : ce qu'il faut comprendre

1Créer un élément en 3 étapes

  • 1. Créer : const li = document.createElement("li"); (l'élément existe, mais n'est pas encore dans la page).
  • 2. Remplir : li.textContent = "…";, li.classList.add("…");.
  • 3. Ajouter dans un parent : liste.append(li); (à la fin) ou liste.prepend(li); (au début).
HTML
<ul id="liste">
  <li>Pain</li>
</ul>
JavaScript
const liste = document.querySelector("#liste");

const li = document.createElement("li");
li.textContent = "Lait (ajouté par JS)";
liste.append(li);
Résultat

2Ajouter à chaque clic

HTML
<input id="article" placeholder="Un article">
<button id="ajouter">Ajouter</button>
<ul id="courses"></ul>
JavaScript
const champ = document.querySelector("#article");
const courses = document.querySelector("#courses");

document.querySelector("#ajouter").addEventListener("click", function () {
  if (champ.value.trim() === "") return;   // rien à ajouter
  const li = document.createElement("li");
  li.textContent = champ.value;
  courses.append(li);
  champ.value = "";     // on vide le champ
  champ.focus();        // le curseur revient dans le champ
});
Résultat

💡 Astuce : return tout seul arrête la fonction tout de suite : pratique pour ignorer un champ vide.

3Supprimer un élément

element.remove() supprime l'élément de la page.

Astuce : on peut ajouter un bouton ✖ dans chaque élément créé, avec son propre addEventListener.

HTML
<ul id="l"></ul>
JavaScript
const l = document.querySelector("#l");
for (const nom of ["Tomates", "Pâtes", "Fromage"]) {
  const li = document.createElement("li");
  li.textContent = nom + " ";
  const croix = document.createElement("button");
  croix.textContent = "✖";
  croix.addEventListener("click", function () {
    li.remove();
  });
  li.append(croix);
  l.append(li);
}
Résultat

💡 Astuce : Clique sur les ✖ dans le résultat. Chaque bouton supprime sa ligne.

4Un élément plus complet : une carte

On peut créer plusieurs éléments et les emboîter, ou utiliser innerHTML pour aller plus vite avec du HTML qu'on a écrit nous-mêmes.

JavaScript
const carte = document.createElement("article");
carte.classList.add("carte");
carte.innerHTML = `
  <h3>${titre}</h3>
  <p>${description}</p>
`;
document.querySelector("#cartes").append(carte);

💡 Astuce : Si le texte vient d'un visiteur, utilise plutôt textContent : c'est plus sûr que innerHTML.

🛠️ Exercices pas à pas

Exercice 1 · La liste de coursesfacile

  1. Crée un champ, un bouton « Ajouter » et une <ul> vide.
  2. Au clic, crée un <li> avec le texte du champ et ajoute-le à la liste.
  3. Vide le champ après l'ajout. N'ajoute rien si le champ est vide.
  4. Remplace le clic par un <form> avec submit pour que la touche Entrée marche.

Exercice 2 · Supprimermoyen

  1. Ajoute un bouton ✖ dans chaque <li> créé.
  2. Au clic sur ✖, supprime la ligne avec li.remove().
  3. Ajoute un bouton « Tout effacer » qui vide la liste (liste.innerHTML = "").

Exercice 3 · Le compteur d'articlesmoyen

  1. Affiche au-dessus de la liste : « 3 articles ».
  2. Crée une fonction mettreAJourCompteur() qui compte les li avec querySelectorAll("#courses li").length.
  3. Appelle-la après chaque ajout et chaque suppression.
  4. Quand la liste est vide, affiche « Ta liste est vide 🛒 ».

🏆 Défi bonus : Le livre d'or

Crée un formulaire « Prénom + message ». Chaque envoi ajoute une carte en haut de la liste (prepend) avec le prénom en gras, le message et l'heure (new Date().toLocaleTimeString()).

Bonus : un bouton ❤️ sur chaque carte avec son propre compteur de likes.

⚠️ Erreurs fréquentes

document.createElement("<li>") avec les chevrons
Juste le nom : createElement("li")
Tous les éléments ont le même texte
Je lis champ.value à l'intérieur de la fonction du clic
append sur le mauvais parent : les lignes vont n'importe où
Je vérifie quel parent j'ai sélectionné

📚 Vocabulaire

createElement
Crée un nouvel élément HTML (pas encore affiché).
append / prepend
Ajoute un élément à la fin / au début d'un parent.
remove
Supprime un élément de la page.
Parent / enfant
Un élément qui en contient un autre / l'élément contenu.
focus()
Met le curseur dans un champ.
