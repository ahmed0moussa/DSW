Séance 03 · Les variables

Un programme a besoin de retenir des informations : un prénom, un score, un prix. Pour ça, on utilise des variables, comme des boîtes avec une étiquette.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, console F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer une variable avec let ou const et changer sa valeur.
  • Reconnaître les types de données : nombre, texte (chaîne), booléen.
  • Faire des calculs et coller des textes ensemble.

🔁 Rappel

Le JavaScript s'écrit dans un fichier .js relié avant </body>. console.log() affiche un message dans la console (F12). Une erreur s'affiche en rouge avec le numéro de ligne.

📒 La note : ce qu'il faut comprendre

1Une variable = une boîte avec une étiquette

Une variable garde une valeur en mémoire. On lui donne un nom (l'étiquette) et une valeur (ce qu'il y a dans la boîte).

let crée une variable dont la valeur peut changer. Le = veut dire « range dans la boîte » (et pas « est égal à » comme en maths).

JavaScript
let prenom = "Yasmine";
let score = 0;

console.log(prenom);
console.log(score);

score = 10;          // on change la valeur
console.log(score);
Résultat

2let ou const ?

  • let : la valeur peut changer (un score, une vie qui diminue).
  • const : la valeur ne change jamais (une constante : ta date de naissance, le nombre de jours dans une semaine).
JavaScript
const joursParSemaine = 7;
let vies = 3;
vies = vies - 1;   // OK : let peut changer
// joursParSemaine = 8;  → erreur ! const ne change pas

💡 Astuce : Règle simple : utilise const par défaut, et let seulement si la valeur doit changer.

3Les types de données

  • Nombre (number) : 14, 3.5, -2. Sans guillemets.
  • Texte (string, « chaîne de caractères ») : "Bonjour". Toujours entre guillemets.
  • Booléen (boolean) : true (vrai) ou false (faux). Pratique pour les conditions.
JavaScript
const age = 14;               // nombre
const ville = "Sfax";        // texte
const estInscrit = true;     // booléen
console.log(typeof age, typeof ville, typeof estInscrit);
Résultat

4Calculer avec des variables

Les opérateurs : + (plus), - (moins), * (fois), / (divisé), % (reste de la division).

JavaScript
const prixGlace = 2.5;
const nombre = 4;
const total = prixGlace * nombre;
console.log("Total :", total, "DT");

let points = 10;
points = points + 5;   // on ajoute 5
points += 5;           // pareil, en plus court
console.log(points);
Résultat

5Coller des textes

Le + entre deux textes les colle (on dit concaténer).

Attention : "5" + 3 donne "53" ! Si l'un des deux est un texte, JavaScript colle au lieu de calculer.

Il existe une écriture plus pratique avec des accents graves (Alt Gr + 7) et ${ } pour mettre une variable dans un texte.

JavaScript
const prenom = "Amine";
const age = 15;
console.log("Salut " + prenom + " !");
console.log(`${prenom} a ${age} ans.`);
console.log("5" + 3);   // "53" et pas 8 !
Résultat

⚠️ Erreurs fréquentes

J'oublie let ou const la première fois
On crée la variable une fois avec let ou const, ensuite on utilise juste son nom
J'écris let prenom = Yasmine; sans guillemets
Un texte va entre guillemets : "Yasmine"
"10" + 5 donne "105"
Un nombre s'écrit sans guillemets : 10 + 5
Je mets des espaces ou des accents dans le nom : let mon âge
Noms sans espace ni accent : monAge (on colle les mots, majuscule au début de chaque mot)
Je change une const : erreur « Assignment to constant variable »
J'utilise let si la valeur doit changer
