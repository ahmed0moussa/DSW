Séance 14 · Les objets : des fiches de données

Un produit a un nom, un prix, une image. Un joueur a un pseudo, un score, un avatar. Pour regrouper toutes les infos d'une même chose, on utilise un objet. Et un tableau d'objets permet de générer automatiquement toutes les cartes d'une boutique !

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Créer un objet avec des propriétés et lire une propriété avec le point (produit.prix).
  • Ranger plusieurs objets dans un tableau.
  • Générer automatiquement des cartes dans la page à partir d'un tableau d'objets.

🔁 Rappel

Un tableau : ["a", "b"], l'indice commence à 0, push, length, for…of. Une fonction afficher() reconstruit la page à partir du tableau.

📒 La note : ce qu'il faut comprendre

1Un objet = une fiche

Un objet s'écrit entre accolades { }. Il contient des propriétés : un nom, deux-points, une valeur.

On lit une propriété avec un point : objet.propriete.

JavaScript
const joueur = {
  pseudo: "NourGamer",
  age: 15,
  score: 1200,
  enLigne: true
};

console.log(joueur.pseudo);
console.log(joueur.score);
joueur.score += 100;          // on modifie
console.log(joueur.score);
Résultat

2Un tableau d'objets

Le format le plus utilisé du web : une liste de fiches. C'est comme ça que les sites gardent leurs produits, leurs articles, leurs vidéos…

JavaScript
const produits = [
  { nom: "Maillot", prix: 45, emoji: "👕" },
  { nom: "Ballon", prix: 30, emoji: "⚽" },
  { nom: "Casquette", prix: 20, emoji: "🧢" }
];

console.log(produits[1].nom);    // "Ballon"
for (const p of produits) {
  console.log(p.emoji + " " + p.nom + " : " + p.prix + " DT");
}
Résultat

3Générer des cartes

Une boucle sur le tableau + createElement = toutes les cartes de la boutique sont créées automatiquement. Pour ajouter un produit, on ajoute juste une ligne dans le tableau !

HTML
<div id="boutique"></div>
CSS
#boutique { display: flex; gap: 8px; flex-wrap: wrap; }
.carte { border: 2px solid #dde3ea; border-radius: 10px; padding: 10px; width: 110px; text-align: center; }
.carte .emoji { font-size: 32px; }
JavaScript
const produits = [
  { nom: "Maillot", prix: 45, emoji: "👕" },
  { nom: "Ballon", prix: 30, emoji: "⚽" },
  { nom: "Casquette", prix: 20, emoji: "🧢" }
];
const boutique = document.querySelector("#boutique");

for (const p of produits) {
  const carte = document.createElement("div");
  carte.classList.add("carte");
  carte.innerHTML = `<div class="emoji">${p.emoji}</div>
                     <strong>${p.nom}</strong><br>${p.prix} DT`;
  boutique.append(carte);
}
Résultat

💡 Astuce : Ici innerHTML ne pose pas de problème : les textes viennent de notre tableau, pas d'un visiteur.

4Filtrer et trier

  • produits.filter(p => p.prix < 40) : un nouveau tableau avec seulement les produits à moins de 40 DT.
  • produits.sort((a, b) => a.prix - b.prix) : trie du moins cher au plus cher.
  • p => … est une fonction fléchée : une façon courte d'écrire une petite fonction.
JavaScript
const pasCher = produits.filter(p => p.prix < 40);
console.log(pasCher.length + " produits à moins de 40 DT");

🛠️ Exercices pas à pas

Exercice 1 · Ma fiche en objetfacile

  1. Crée un objet moi avec : prenom, age, ville, passions (un tableau !).
  2. Affiche dans la page : « Je m'appelle … j'ai … ans ».
  3. Affiche la liste de tes passions en <li> avec une boucle sur moi.passions.

Exercice 2 · La boutique du clubmoyen

  1. Crée un tableau produits d'au moins 6 objets : nom, prix, image (une adresse Picsum), categorie.
  2. Écris une fonction afficher(liste) qui crée une carte par produit (image, nom, prix) dans une grille CSS.
  3. Appelle afficher(produits).

Exercice 3 · Filtres et tridifficile

  1. Ajoute des boutons de catégorie : au clic, afficher(produits.filter(p => p.categorie === "…")).
  2. Ajoute un bouton « Tout voir ».
  3. Ajoute un bouton « Prix croissant » qui trie avec sort puis réaffiche.

🏆 Défi bonus : Le panier

Ajoute un bouton « Ajouter au panier » sur chaque carte. Un tableau panier reçoit les produits, et en haut de la page on voit « 🛒 3 articles · 95 DT ». Bonus : un bouton pour vider le panier.

⚠️ Erreurs fréquentes

J'écris produit[nom] ou produit->nom
On utilise le point : produit.nom
J'oublie les virgules entre les propriétés
{ nom: "Ballon", prix: 30 } : une virgule entre chaque propriété
produits.nom donne undefined
produits est un tableau : il faut un élément d'abord, produits[0].nom, ou une boucle
Mon filtre ne trouve rien
Je vérifie l'orthographe exacte de la catégorie (majuscules, accents)
