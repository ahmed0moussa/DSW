Séance 12 · Mini-projet : ma to-do list

Fin du module 2 ! Tu construis une vraie petite application : une liste de tâches (to-do list). On ajoute des tâches, on les coche quand elles sont faites, on les supprime, et un compteur suit tout ça.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Intermédiaire · Mini-projet
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Construire une application complète en assemblant DOM, événements, formulaires et création d'éléments.
  • Découper un projet en petites fonctions qui ont chacune un rôle.
  • Tester et déboguer son application avec la console.

🔁 Rappel

Module 2 : querySelector, textContent, classList, addEventListener, .value, submit + preventDefault, createElement, append, remove.

📒 La note : ce qu'il faut comprendre

1Le cahier des charges

  • Un champ + un bouton pour ajouter une tâche (la touche Entrée marche aussi).
  • Chaque tâche a une case ou un clic pour la cocher (texte barré).
  • Chaque tâche a un bouton ✖ pour la supprimer.
  • Un compteur : « 2 tâches restantes ».
  • Bonus : un bouton « Effacer les tâches terminées ».

2Découper en fonctions

Avant de coder, on découpe le travail. Chaque fonction a un seul rôle :

JavaScript
function creerTache(texte) { … }     // crée le <li> et ses boutons
function mettreAJourCompteur() { … }  // compte les tâches restantes

formulaire.addEventListener("submit", function (e) {
  e.preventDefault();
  creerTache(champ.value);
  mettreAJourCompteur();
});

💡 Astuce : Écris d'abord les étapes en commentaires, puis remplis chaque fonction. Teste après chaque petite étape.

3Cocher une tâche : toggle

HTML
<ul><li id="t">Faire mes devoirs (clique-moi)</li></ul>
CSS
.fait { text-decoration: line-through; color: gray; }
JavaScript
const tache = document.querySelector("#t");
tache.addEventListener("click", function () {
  tache.classList.toggle("fait");
});
Résultat

4Compter seulement les tâches restantes

Le sélecteur CSS :not(.fait) sélectionne les tâches qui n'ont pas la classe fait.

JavaScript
function mettreAJourCompteur() {
  const restantes = document.querySelectorAll("#taches li:not(.fait)").length;
  compteur.textContent = restantes + " tâche(s) restante(s)";
}

🛠️ Exercices pas à pas

Exercice 1 · Ajouter des tâchesmoyen

  1. HTML : un <form> (champ + bouton), une <ul id="taches"> vide, un <p id="compteur">.
  2. Crée la fonction creerTache(texte) qui crée un <li> et l'ajoute à la liste.
  3. À l'envoi du formulaire : preventDefault, ignorer si vide, creerTache, vider le champ.

Exercice 2 · Cocher et supprimermoyen

  1. Dans creerTache, au clic sur le texte de la tâche : classList.toggle("fait").
  2. Ajoute un bouton ✖ qui supprime la tâche.
  3. Style : .fait barré et gris, le bouton ✖ à droite (Flexbox !).

Exercice 3 · Le compteur et le nettoyagedifficile

  1. Crée mettreAJourCompteur() avec :not(.fait). Appelle-la après chaque ajout, chaque coche et chaque suppression.
  2. Ajoute un bouton « Effacer les tâches terminées » : une boucle sur querySelectorAll(".fait") qui fait remove().
  3. Quand il n'y a plus de tâche : « Rien à faire, bravo ! 🎉 ».

🏆 Défi bonus : Les priorités

Ajoute une liste <select> « Priorité » (🔴 urgent, 🟠 normal, 🟢 pas pressé). La tâche reçoit une classe selon la priorité, et les tâches urgentes s'ajoutent en haut de la liste (prepend).

À la séance 15, on fera en sorte que la liste soit sauvegardée même si on ferme la page !

⚠️ Erreurs fréquentes

Le compteur n'est pas à jour
J'appelle mettreAJourCompteur() après chaque changement
Cliquer sur ✖ coche aussi la tâche
J'écoute le clic sur le texte (un <span>) et pas sur tout le <li>
J'ai écrit tout le code d'un coup et rien ne marche
Je teste après chaque petite étape et je lis la console
Des tâches vides s'ajoutent
