Séance 08 · Changer le style avec JavaScript

JavaScript peut aussi changer l'apparence : couleurs, tailles, affichage. La meilleure méthode : préparer des classes en CSS, et laisser JavaScript les ajouter ou les enlever.

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Débutant
  • 🧰 Outils : VS Code, Live Server, F12
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Changer un style directement avec la propriété style.
  • Ajouter, enlever et basculer une classe avec classList.add, remove et toggle.
  • Combiner DOM, boucle et condition pour colorer automatiquement une page.

🔁 Rappel

document.querySelector("#id") trouve un élément, textContent change son texte, querySelectorAll + for…of change plusieurs éléments.

📒 La note : ce qu'il faut comprendre

1La propriété style

element.style.propriete = "valeur". Les noms de propriétés CSS avec un tiret s'écrivent sans tiret, avec une majuscule : background-color devient backgroundColor.

HTML
<p id="texte">Je vais changer de style</p>
JavaScript
const texte = document.querySelector("#texte");
texte.style.color = "white";
texte.style.backgroundColor = "#288b8b";
texte.style.padding = "10px";
texte.style.borderRadius = "8px";
Résultat

2Mieux : les classes avec classList

On écrit le style dans le CSS (une classe), et JavaScript se contente d'ajouter ou d'enlever la classe. Le code est plus propre et plus facile à modifier.

  • element.classList.add("nom") : ajoute la classe.
  • element.classList.remove("nom") : enlève la classe.
  • element.classList.toggle("nom") : l'ajoute si elle n'y est pas, l'enlève si elle y est (interrupteur).
  • element.classList.contains("nom") : true si l'élément a la classe.
HTML
<p id="msg">Attention !</p>
CSS
.alerte { background: #fbeaea; color: #c0392b; border-left: 5px solid #c0392b; padding: 8px; }
JavaScript
document.querySelector("#msg").classList.add("alerte");
Résultat

3Montrer et cacher

Une classe .cache { display: none; } + classList = on peut montrer ou cacher n'importe quoi.

HTML
<p class="secret cache">Message secret 🤫</p>
<p>Le message secret est caché.</p>
CSS
.cache { display: none; }
JavaScript
// Pour le montrer :
document.querySelector(".secret").classList.remove("cache");

4Colorer automatiquement : boucle + condition + classe

Exemple : un bulletin dont les notes se colorent toutes seules en vert ou en rouge.

HTML
<ul>
  <li class="note">14</li>
  <li class="note">8</li>
  <li class="note">17</li>
  <li class="note">9</li>
</ul>
CSS
.reussi { color: #2e8b57; font-weight: bold; }
.echec { color: #c0392b; font-weight: bold; }
JavaScript
const notes = document.querySelectorAll(".note");
for (const note of notes) {
  const valeur = Number(note.textContent);
  if (valeur >= 10) {
    note.classList.add("reussi");
  } else {
    note.classList.add("echec");
  }
}
Résultat

💡 Astuce : textContent est toujours un texte : on le transforme en nombre avec Number() avant de comparer.

🛠️ Exercices pas à pas

Exercice 1 · Je repeins ma pagefacile

  1. Crée une page avec un titre, 3 paragraphes et une image.
  2. Avec style, change la couleur du titre, le fond du body et la taille du texte d'un paragraphe.
  3. Arrondis l'image avec style.borderRadius.

Exercice 2 · Les classesfacile

  1. Dans ton CSS, crée les classes .important (fond jaune, gras) et .cache (display: none).
  2. Avec classList.add, rends le 2e paragraphe important.
  3. Cache l'image avec la classe .cache, puis montre-la à nouveau avec remove.
  4. Utilise classList.toggle("important") deux fois de suite sur le même paragraphe : que se passe-t-il ?

Exercice 3 · Le bulletin colorémoyen

  1. Crée un tableau HTML de 6 matières avec leur note (une cellule <td class="note">).
  2. Avec querySelectorAll et une boucle, colore en vert les notes ≥ 10 et en rouge les autres (avec des classes).
  3. Ajoute une classe .excellent (avec un 🏆) pour les notes ≥ 16.

🏆 Défi bonus : Le classement du championnat

Fais un tableau de 6 équipes avec leurs points. Avec JavaScript : la 1re ligne en or, les 3 premières en vert, la dernière en rouge (« relégation »). Indice : querySelectorAll("tr") donne une liste, et la position se trouve avec un compteur dans la boucle.

⚠️ Erreurs fréquentes

style.background-color = … : erreur
Sans tiret : style.backgroundColor
style.width = 200; ne marche pas
Avec l'unité, entre guillemets : "200px"
classList.add(".reussi") avec le point
Sans le point : classList.add("reussi")
Je mets tout le style en JavaScript
Le style va dans le CSS (des classes), JavaScript ajoute ou enlève les classes

📚 Vocabulaire

style
Le style en ligne d'un élément, modifiable en JavaScript.
classList
La liste des classes d'un élément.
add / remove
Ajouter / enlever une classe.
toggle
Ajouter ou enlever une classe selon qu'elle est déjà là (un interrupteur).
camelCase
L'écriture backgroundColor : mots collés, majuscule à chaque nouveau mot.
