🎯 Objectif : à la fin de la séance, je saurai…

  • Créer une fonction et l'appeler.
  • Donner des paramètres à une fonction et récupérer un résultat avec return.
  • Programmer le jeu « Devine le nombre » avec des variables, des conditions, une boucle et des fonctions.

🔁 Rappel

Les boucles : for (let i = 1; i <= 10; i++) { … } répète un nombre précis de fois, while (condition) { … } répète tant que c'est vrai.

📒 La note : ce qu'il faut comprendre

1Créer et appeler une fonction

On déclare la fonction avec function, un nom, des parenthèses et des accolades. Rien ne se passe tant qu'on ne l'appelle pas avec son nom suivi de ().

JavaScript
function direBonjour() {
  console.log("Bonjour !");
  console.log("Bienvenue au club 👋");
}

direBonjour();   // on l'appelle
direBonjour();   // et encore une fois
Résultat

2Les paramètres

Un paramètre est une information qu'on donne à la fonction. Elle peut changer à chaque appel.

JavaScript
function saluer(prenom) {
  console.log("Salut " + prenom + " !");
}

saluer("Nour");
saluer("Youssef");
Résultat

3Renvoyer un résultat : return

return renvoie une valeur. On peut la ranger dans une variable.

JavaScript
function calculerPrix(prix, quantite) {
  return prix * quantite;
}

const total = calculerPrix(2.5, 4);
console.log("À payer : " + total + " DT");
Résultat

💡 Astuce : Pense à une machine à jus : tu mets des oranges (les paramètres), elle te rend un jus (le return).

4Parler au visiteur : prompt et alert

  • alert("message") : affiche une fenêtre avec un message.
  • prompt("question") : pose une question et renvoie la réponse sous forme de texte.
  • Number(texte) : transforme un texte en nombre ("12" devient 12).
JavaScript
const reponse = prompt("Quel âge as-tu ?");
const age = Number(reponse);
alert("Dans 10 ans, tu auras " + (age + 10) + " ans !");

💡 Astuce : prompt et alert sont parfaits pour apprendre, mais les vrais sites ne les utilisent presque pas. Au module 2, on parlera directement à la page !

5Le hasard : Math.random

Math.random() donne un nombre au hasard entre 0 et 1. Pour avoir un nombre entier entre 1 et 100 :

JavaScript
const secret = Math.floor(Math.random() * 100) + 1;
console.log(secret);
Résultat

💡 Astuce : Math.floor() arrondit vers le bas. Recharge le cadre (ou la page) : le nombre change à chaque fois.

🛠️ Exercices pas à pas

Exercice 1 · Mes premières fonctionsfacile

  1. Crée une fonction presenter(prenom, age) qui affiche « Je m'appelle … et j'ai … ans ».
  2. Appelle-la 3 fois avec des personnes différentes.
  3. Crée une fonction carre(n) qui renvoie n * n, et affiche carre(7).
  4. Crée une fonction estMajeur(age) qui renvoie true si age >= 18, sinon false.

Exercice 2 · Devine le nombre : l'algorithmemoyen

  1. Écris d'abord en français (en commentaires) : l'ordinateur choisit un nombre secret entre 1 et 100 ; RÉPÉTER : le joueur propose, SI trop petit… SI trop grand… SI trouvé : bravo et on s'arrête.
  2. Crée const secret avec Math.random().
  3. Crée let essais = 0; et let trouve = false;.

Exercice 3 · Devine le nombre : le codedifficile

  1. Avec while (!trouve), demande un nombre avec prompt et transforme-le avec Number.
  2. Si le joueur clique sur Annuler, prompt renvoie null : arrête la boucle avec break.
  3. Ajoute 1 à essais à chaque tour. Affiche « C'est plus ! » ou « C'est moins ! » avec alert.
  4. Quand c'est trouvé : « Bravo, trouvé en … essais ! 🎉 » et trouve = true.
  5. Range le message du résultat dans une fonction messageResultat(essais) qui renvoie un texte différent selon le nombre d'essais.

🏆 Défi bonus : Les niveaux de difficulté

Au début du jeu, demande le niveau : facile (1 à 20), moyen (1 à 100), difficile (1 à 1000). Crée une fonction nombreAuHasard(max) qui renvoie un nombre entre 1 et max.

Bonus : limite le nombre d'essais (10 maximum) et affiche « Perdu ! Le nombre était … ».

⚠️ Erreurs fréquentes

Ma fonction ne fait rien
Il faut l'appeler : direBonjour();
J'oublie return : ma variable vaut undefined
La fonction doit renvoyer la valeur avec return
prompt renvoie "12" et mes comparaisons sont fausses
Je transforme en nombre : Number(reponse)
Le jeu ne s'arrête jamais quand je clique sur Annuler
Je teste if (reponse === null) { break; }

📚 Vocabulaire

Fonction
Un bloc de code avec un nom, qu'on peut réutiliser.
Appeler
Lancer une fonction : nom().
Paramètre
Une information donnée à la fonction.
return
Renvoie un résultat et termine la fonction.
prompt / alert
Poser une question / afficher un message dans une fenêtre.
break
Sortir d'une boucle tout de suite.
