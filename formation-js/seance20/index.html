Séance 20 · Projet 4/4 : publier et présenter

Dernière séance ! Tu termines tes interactions, tu vérifies tout, tu mets ton site interactif en ligne… et tu le présentes à la classe. 🎉

  • ⏱️ Durée : 2 h
  • 📶 Niveau : Projet
  • 🧰 Outils : VS Code, F12, Netlify Drop ou GitHub Pages
🎯 Objectif📒 La note⏱️ Déroulé🛠️ Exercices🏆 Défi⚠️ Erreurs📚 Vocabulaire🔗 Ressources✅ Je vérifie

🎯 Objectif : à la fin de la séance, je saurai…

  • Terminer et vérifier mes interactions (checklist qualité, 0 erreur dans la console).
  • Publier mon site interactif en ligne.
  • Présenter mon site et expliquer une partie de mon code JavaScript.

🔁 Rappel

Séances 17 à 19 : plan d'interactions, menu burger, mode sombre, retour en haut, diaporama, accordéon, galerie filtrée, tests en binôme.

📒 La note : ce qu'il faut comprendre

1La checklist qualité JavaScript

  • Aucune erreur rouge dans la console, sur toutes les pages.
  • Chaque interaction marche sur ordinateur et en mode téléphone.
  • Le site reste utilisable si une interaction ne se lance pas (le contenu important est visible).
  • Le code est rangé : des fonctions avec des noms clairs, des commentaires pour chaque partie.
  • Pas de code inutile ni de console.log de test oublié.

2Mettre en ligne

Comme pour la formation HTML/CSS : Netlify Drop (glisser le dossier) ou GitHub Pages. Le dossier js/ doit être envoyé avec le reste !

💡 Astuce : Après la mise en ligne, ouvre ton site en ligne avec la console : vérifie qu'il n'y a pas d'erreur (un chemin js/script.js mal écrit, une majuscule…).

3Présenter (3 minutes)

  • 1. Mon site et son public, en une phrase.
  • 2. La démonstration de chaque interaction.
  • 3. Le code d'une interaction : j'explique l'algorithme QUAND / ALORS et les lignes importantes.
  • 4. Un bug difficile et comment je l'ai résolu.
  • 5. Ce que j'aimerais apprendre ensuite.

4Et après ?

Tu sais maintenant créer un site complet et interactif. Pour aller plus loin :

  • Les API : récupérer des données d'Internet (météo, films…) avec fetch.
  • Les jeux : dessiner et animer avec <canvas>.
  • Les frameworks : React, Vue… utilisés par les grandes entreprises.
  • Le back-end : Node.js, pour coder aussi le côté serveur.

💡 Astuce : Continue sur fr.javascript.info, W3Schools et CodeCombat. Et surtout : construis des projets qui te plaisent !

👉 Ouvre l'exemple complet de la séance, puis fais clic droit → Inspecter pour voir son code.

🛠️ Exercices pas à pas

Exercice 1 · Les finitionsmoyen

  1. Termine les interactions de ton plan.
  2. Range ton script.js : une partie par interaction, avec un commentaire de titre.
  3. Enlève les console.log de test.

Exercice 2 · La checklist qualitémoyen

  1. Passe la checklist (notion 1) page par page.
  2. Teste en mode téléphone et sur un vrai téléphone si possible.
  3. Fais tester une dernière fois par ton voisin.

Exercice 3 · Publierfacile

  1. Publie ton site sur Netlify Drop ou GitHub Pages.
  2. Ouvre le site en ligne avec la console : 0 erreur ?
  3. Envoie l'adresse au formateur et prépare ta présentation.

🏆 Défi bonus : Une API

Ajoute à ton site une information venue d'Internet grâce à fetch : une citation au hasard, la météo de ta ville… (cherche « fetch API » sur W3Schools). Attention : certaines API demandent une clé, choisis-en une gratuite et sans inscription.

⚠️ Erreurs fréquentes

Le site en ligne n'a pas de JavaScript
Le dossier js/ doit être envoyé et le chemin respecter les majuscules
Une interaction casse toutes les autres
Une erreur arrête le script : je lis la console et je corrige la première erreur
Je lis mon code ligne par ligne pendant la présentation
J'explique l'algorithme avec mes mots, puis je montre 3 ou 4 lignes importantes
J'ajoute une nouvelle interaction le dernier jour
Aujourd'hui, on finit et on vérifie ; les nouveautés, ce sera pour après !
