📒 La note : ce qu'il faut comprendre

1Le DOM : la page vue par JavaScript

Quand le navigateur lit ton HTML, il construit un arbre d'éléments : le DOM (Document Object Model). document représente toute la page.

Chaque balise devient un objet que JavaScript peut trouver et modifier. Les changements se voient tout de suite à l'écran.

Schéma
document
└── html
    ├── head
    │   └── title
    └── body
        ├── h1  « Bienvenue »
        └── p   « Bonjour »

💡 Astuce : F12 → onglet Elements : c'est exactement le DOM. Quand JavaScript change la page, tu le vois changer là aussi.

2Trouver un élément : querySelector

document.querySelector("sélecteur") trouve le premier élément qui correspond. On utilise les mêmes sélecteurs qu'en CSS !

On range l'élément trouvé dans une variable pour l'utiliser ensuite.

HTML
<h1 id="titre">Bonjour</h1>
<p class="message">Texte de départ</p>
JavaScript
const titre = document.querySelector("#titre");
const message = document.querySelector(".message");

titre.textContent = "Bienvenue au club ! 🎉";
message.textContent = "Ce texte a été changé par JavaScript.";
Résultat

3textContent ou innerHTML ?

  • textContent : change le texte seulement (le plus sûr).
  • innerHTML : change le HTML à l'intérieur (on peut ajouter des balises comme <strong>).
HTML
<p id="a"></p>
<p id="b"></p>
JavaScript
document.querySelector("#a").textContent = "<strong>Gras ?</strong>";
document.querySelector("#b").innerHTML = "<strong>Gras !</strong>";
Résultat

💡 Astuce : N'utilise innerHTML qu'avec du texte que toi tu as écrit, jamais avec ce qu'un visiteur a tapé (il pourrait y glisser du code).

4Changer un attribut

On peut changer les attributs : src d'une image, href d'un lien, alt…

HTML
<img id="photo" src="https://picsum.photos/seed/chat/160/100" alt="Une photo" width="160">
JavaScript
const photo = document.querySelector("#photo");
photo.src = "https://picsum.photos/seed/plage/160/100";
photo.alt = "Une plage";

5Trouver plusieurs éléments : querySelectorAll

querySelectorAll renvoie tous les éléments qui correspondent. On les parcourt avec une boucle for…of.

HTML
<ul>
  <li class="fruit">pomme</li>
  <li class="fruit">banane</li>
  <li class="fruit">orange</li>
</ul>
JavaScript
const fruits = document.querySelectorAll(".fruit");
for (const fruit of fruits) {
  fruit.textContent = fruit.textContent.toUpperCase() + " ✅";
}
Résultat

⚠️ Erreurs fréquentes

querySelector("titre") ne trouve rien (null)
Il faut le sélecteur complet : "#titre" pour un id, ".intro" pour une classe
Erreur « Cannot set properties of null »
L'élément n'a pas été trouvé : je vérifie le sélecteur et que le <script> est à la fin du <body>
J'écris textcontent ou TextContent
Majuscules exactes : textContent, innerHTML, querySelector
querySelectorAll(...).textContent = … ne marche pas
querySelectorAll renvoie une liste : j'utilise une boucle for…of

📚 Vocabulaire

DOM
L'arbre des éléments de la page, que JavaScript peut modifier.
document
L'objet qui représente toute la page.
querySelector
Trouve le premier élément qui correspond à un sélecteur CSS.
querySelectorAll
Trouve tous les éléments qui correspondent.
textContent
Le texte d'un élément.
innerHTML
Le HTML à l'intérieur d'un élément.
null
« Rien » : par exemple quand un élément n'a pas été trouvé.
