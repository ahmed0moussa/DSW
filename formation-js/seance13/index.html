Une playlist, une liste d'élèves, les questions d'un quiz… Quand on a plusieurs valeurs du même genre, on les range dans un tableau (array). Et avec une boucle, on les affiche toutes d'un coup dans la page.

📒 La note : ce qu'il faut comprendre

1Créer un tableau

Un tableau s'écrit entre crochets [ ], les valeurs séparées par des virgules. Chaque valeur a une position, l'indice, qui commence à 0 !

JavaScript
const playlist = ["Calme", "Bella", "Dynamite", "Habibi"];

console.log(playlist[0]);       // le 1er : "Calme"
console.log(playlist[2]);       // le 3e : "Dynamite"
console.log(playlist.length);   // 4 éléments
Résultat

💡 Astuce : Le dernier élément est à l'indice length - 1 : playlist[playlist.length - 1].

2Ajouter, enlever, modifier

  • tableau.push(valeur) : ajoute à la fin.
  • tableau.pop() : enlève le dernier.
  • tableau.splice(indice, 1) : enlève l'élément à cet indice.
  • tableau[1] = "…" : remplace l'élément à l'indice 1.
  • tableau.includes(valeur) : true si la valeur est dans le tableau.
JavaScript
const courses = ["pain", "lait"];
courses.push("œufs");
console.log(courses);
courses.splice(0, 1);    // enlève "pain"
console.log(courses);
console.log(courses.includes("lait"));
Résultat

💡 Astuce : Un tableau créé avec const peut quand même changer de contenu : const empêche seulement de le remplacer par un autre tableau.

3Parcourir un tableau

for (const element of tableau) passe sur chaque élément, un par un.

JavaScript
const notes = [12, 15, 9, 17];
let somme = 0;
for (const note of notes) {
  somme += note;
}
console.log("Moyenne :", somme / notes.length);
Résultat

4Du tableau à la page

Le grand classique : on garde les données dans un tableau, et une fonction affiche tout le tableau dans la page. Quand le tableau change, on rappelle la fonction.

HTML
<ul id="liste"></ul>
<button id="ajouter">Ajouter un titre</button>
JavaScript
const playlist = ["Calme", "Bella", "Dynamite"];
const liste = document.querySelector("#liste");

function afficher() {
  liste.innerHTML = "";              // on vide
  for (const titre of playlist) {    // on recrée tout
    const li = document.createElement("li");
    li.textContent = "🎵 " + titre;
    liste.append(li);
  }
}

document.querySelector("#ajouter").addEventListener("click", function () {
  playlist.push("Nouveau titre " + (playlist.length + 1));
  afficher();
});

afficher();
Résultat

5Un élément au hasard

JavaScript
const blagues = ["Blague 1…", "Blague 2…", "Blague 3…"];
const indice = Math.floor(Math.random() * blagues.length);
console.log(blagues[indice]);

💡 Astuce : Math.random() * blagues.length donne un nombre entre 0 et la taille du tableau : parfait pour un indice au hasard.

⚠️ Erreurs fréquentes

playlist[1] me donne le 2e élément, pas le 1er
Normal : les indices commencent à 0
playlist[playlist.length] vaut undefined
Le dernier est à length - 1
Ma liste dans la page affiche les titres en double
Dans afficher(), je vide d'abord : liste.innerHTML = ""
J'oublie d'appeler afficher() après un push
Le tableau change, mais la page ne se met à jour que si je rappelle afficher()

📚 Vocabulaire

Tableau (array)
Une liste de valeurs entre crochets [ ].
Indice
La position d'un élément, en commençant à 0.
length
Le nombre d'éléments du tableau.
push / pop
Ajouter à la fin / enlever le dernier.
splice
Enlever (ou ajouter) des éléments à une position.
Parcourir
Passer sur chaque élément avec une boucle.
